# 《孙子兵法》知识图谱长图视觉设计需求

> 本文件用于指导设计师（或 AI 绘图工具）生成适用于公众号排版的《孙子兵法》系列知识图谱长图。
> **设计风格**：**“军事沙盘风”** 或 **“现代数据可视化风”**。强调严谨、逻辑、策略。
> **配色建议**：**黑金（严肃/权力）** 搭配 **烽火红（警示/能量）** 或 **冷蓝（科技/计算）**。
> **尺寸建议**：1080x1920 px（竖屏）。

---

## 🖼️ 图片 1：五事七计 —— 赢家的“战前 Checklist"

*   **用途**：用于【第 2 篇：图谱逻辑】，展示战略评估模型。
*   **视觉概念**：**一个五边形的雷达图 / 古代兵符 / 现代仪表盘**。
    *   **Center: 庙算 (Temple Calculations)**
        *   含义：打之前的计算。
        *   标注："多算胜，少算不胜"。
    *   **Dimension 1: 道 (The Way / Morale)**
        *   含义：上下同欲，目标一致。
        *   标注："令民与上同意也"。
    *   **Dimension 2: 天 (Heaven / Timing)**
        *   含义：时机、天气、宏观环境。
        *   标注："阴阳、寒暑、时制也"。
    *   **Dimension 3: 地 (Earth / Terrain)**
        *   含义：地形、距离、险易。
        *   标注："远近、险易、广狭、死生也"。
    *   **Dimension 4: 将 (Commander / Leadership)**
        *   含义：智、信、仁、勇、严。
        *   标注："将者，智信仁勇严也"。
    *   **Dimension 5: 法 (Method / Discipline)**
        *   含义：制度、后勤、管理。
        *   标注："曲制、官道、主用也"。
*   **底部文字**：通过这五个维度的对比（七计），就能预判胜负。

## 🖼️ 图片 2：奇正相生 —— 势与节的能量转换

*   **用途**：用于【第 3 篇：核心思想】，展示战术执行的节奏感。
*   **视觉概念**：**水流/波浪 / 齿轮咬合**。
    *   **Left: 正 (Orthodox / Standard)**
        *   图像：正面的阵地战，按部就班，正规军。
        *   标注："凡战者，以正合"。
        *   含义：基础盘，稳住阵脚，吸引火力。
    *   **Right: 奇 (Unorthodox / Surprise)**
        *   图像：侧翼的突袭，出奇制胜，特种部队。
        *   标注："以奇胜"。
        *   含义：胜负手，打破常规，致命一击。
    *   **Interaction: 相生 (Cycle)**
        *   图像：正奇循环，奇变为正，正变为奇。
        *   标注："奇正之变，不可胜穷也"。
        *   含义：没有绝对的奇正，要看怎么用。
*   **关键文案**："激水之疾，至于漂石者，势也；鸷鸟之疾，至于毁折者，节也。"

## 🖼️ 图片 3：诡道十二法 —— 信息战的“烟雾弹”

*   **用途**：用于【第 3 篇：核心思想】，展示如何制造信息不对称。
*   **视觉概念**：**十二面镜子 / 迷雾中的信号灯**。
    *   **分类展示**：
        *   **示形 (Deception)**：能而示之不能，用而示之不用。
        *   **诱敌 (Lure)**：利而诱之，乱而取之。
        *   **实备 (Defense)**：实而备之，强而避之。
        *   **攻心 (Psychology)**：怒而挠之，卑而骄之。
        *   **消耗 (Attrition)**：佚而劳之，亲而离之。
    *   **核心逻辑**：
        *   让敌人看到的，都是你想让他看到的。
        *   让敌人做的，都是对他不利的。
*   **关键文案**："攻其无备，出其不意。"

## 🖼️ 图片 4：因敌制胜 —— 像水一样灵活的战略

*   **用途**：用于【第 4 篇：核心思想】，展示适应性和变化。
*   **视觉概念**：**水在不同容器中的形状 / 风向标**。
    *   **Concept: 兵形象水 (War is like Water)**
        *   图像 1：高山 -> 水往低处流 -> 避实击虚（避开强点，攻击弱点）。
        *   图像 2：河道 -> 地形决定流向 -> 因敌制胜（根据敌人变化调整战术）。
        *   图像 3：大海 -> 无边无际 -> 兵无常势（没有固定的赢法）。
    *   **对比**：
        *   死板的战术 -> 被克制。
        *   灵活的战术 -> 无懈可击。
*   **关键文案**："兵无常势，水无常形，能因敌变化而取胜者，谓之神。"
