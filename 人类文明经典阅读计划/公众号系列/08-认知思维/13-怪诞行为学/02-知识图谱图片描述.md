# 《怪诞行为学》知识图谱图片描述

本文档包含4张Mermaid知识图谱，用于可视化《怪诞行为学》的核心概念体系。

---

## 图一：非理性行为分类树（Tree Diagram）

展示人类非理性行为的主要类型及其具体表现。

```mermaid
graph TD
    A["非理性行为 Irrationality"] --> B["相对性判断"]
    A --> C["锚定效应"]
    A --> D["免费诱惑"]
    A --> E["社会与市场规范冲突"]
    A --> F["预期效应"]
    
    B --> B1["诱饵效应 Decoy"]
    B --> B2["对比效应 Contrast"]
    B --> B3["极端规避 Compromise"]
    
    C --> C1["价格锚定"]
    C --> C2["数字锚定"]
    C --> C3["第一印象锚定"]
    
    D --> D1["零价格狂热"]
    D --> D2["免费赠品冲动"]
    D --> D3["免费包邮偏好"]
    
    E --> E1["金钱破坏关系"]
    E --> E2["礼物vs报酬"]
    E --> E3["志愿vs雇佣"]
    
    F --> F1["品牌安慰剂"]
    F --> F2["价格影响体验"]
    F --> F3["期望影响满意度"]
```

**设计说明**：树形结构，自上而下展示六大非理性行为类型及其子类，配色建议从深紫到浅紫的渐变。

## 图二：行为影响因素网络图（Network Diagram）

展示影响人类决策的各种因素之间的交互关系。

```mermaid
graph LR
    P1["感知价值"] --> D1["购买决策"]
    P2["情绪状态"] --> D1
    P3["社会环境"] --> D1
    P4["过往经验"] --> D1
    
    P1 -->|"受锚定影响"| P5["参照系"]
    P2 -->|"受免费影响"| P6["非理性热情"]
    P3 -->|"受规范影响"| P7["关系模式"]
    P4 -->|"受预期影响"| P8["体验滤镜"]
    
    P5 -.->|"强化"| P1
    P6 -.->|"扭曲"| P1
    P7 -.->|"切换"| D1
    P8 -.->|"放大或缩小"| P1
    
    D1 --> R["行为结果"]
```

**设计说明**：网状结构，中心为购买决策，展示各影响因素之间的双向作用关系。

## 图三：理性决策vs非理性决策路径图（Path Diagram）

对比理想中的理性决策路径与实际的非理性决策路径。

```mermaid
graph LR
    START(("面临选择")) --> I1["收集所有信息"]
    I1 --> I2["客观评估每个选项"]
    I2 --> I3["计算效用最大化"]
    I3 --> I4["做出最优选择"]
    I4 --> R1(("理性结果"))
    
    START2(("面临选择")) --> A1["受锚定影响"]
    A1 --> A2["依赖相对比较"]
    A2 --> A3["情绪介入"]
    A3 --> A4["规范切换"]
    A4 --> A5["做出选择"]
    A5 --> R2(("非理性结果"))
    
    A1 -.->|"影响"| A2
    A2 -.->|"影响"| A3
    A3 -.->|"影响"| A4
```

**设计说明**：上下两条并行路径，上方为理想理性路径，下方为实际非理性路径，用虚线连接各步骤体现因果链。
