# 《拆掉思维里的墙》知识图谱图片描述

本文档描述《拆掉思维里的墙》知识图谱的四个 Mermaid 图示，用于公众号排版时生成配图。

---

## 图一：自我设限类型树状图（tree）

展示书中提到的各种自我设限思维的分类体系。

```mermaid
graph TD
    A["思维里的墙"] --> B["安全感陷阱"]
    A --> C["兴趣迷思"]
    A --> D["能力焦虑"]
    A --> E["完美主义"]
    A --> F["比较心理"]
    B --> B1["害怕失去稳定"]
    B --> B2["过度依赖外部保障"]
    C --> C1["等待找到兴趣再行动"]
    C --> C2["把兴趣当成静态目标"]
    D --> D1["等准备好再开始"]
    D --> D2["用不足否定可能性"]
    E --> E1["不做比做错了好"]
    E --> E2["过度追求细节"]
    F --> F1["和别人比而不是和自己比"]
    F --> F2["用他人标准衡量自己"]
```

描述说明：
- 根节点为"思维里的墙"总览
- 第二层分为五种主要的自我设限类型
- 第三层展开每种类型的典型表现
- 用于帮助读者识别自己的思维墙

## 图二：认知突破路径图（path）

展示从"自我设限"到"认知突破"的完整转变路径。

```mermaid
graph TD
    S["觉察：识别限制性信念"] --> R["质疑：这些信念是真的吗"]
    R --> T["尝试：小步行动验证"]
    T --> E["体验：获得新的反馈"]
    E --> P{"信念改变?"}
    P -->|"是"| N["内化：形成新的认知"]
    P -->|"否"| R
    N --> A["行动：基于新认知做决策"]
    A --> G["成长：能力与信心提升"]
    G --> S2["觉察新的限制性信念"]
```

描述说明：
- 从"觉察"限制性信念开始
- 经过"质疑-尝试-体验"的验证循环
- 信念改变后内化为新认知
- 基于新认知行动带来成长
- 形成持续突破的正向飞轮

## 图三：职业甜蜜点关系图（graph）

展示职业选择中"甜蜜点"模型的三要素及其关系。

```mermaid
graph TD
    A["你擅长的"] --> D["能力圈"]
    B["你喜欢的"] --> E["兴趣圈"]
    C["社会需要的"] --> F["需求圈"]
    D --> G["甜蜜点"]
    E --> G
    F --> G
    G --> H["理想职业方向"]
    D -.->|"只有能力"| I["做得好但不快乐"]
    E -.->|"只有兴趣"| J["快乐但难以持久"]
    C -.->|"只有需求"| K["痛苦且平庸"]
```

描述说明：
- 三个独立圆圈分别代表能力、兴趣和需求
- 三者的交集是"甜蜜点"
- 虚线箭头展示只有单一要素时的状态
- 用于直观展示职业选择的核心逻辑

## 图四：兴趣培养循环图（network）

展示兴趣从无到有的动态培养过程。

```mermaid
graph LR
    A["开始尝试"] --> B["获得初步反馈"]
    B --> C["产生好奇心"]
    C --> D["投入更多时间"]
    D --> E["能力提升"]
    E --> F["获得正反馈"]
    F --> G["兴趣加深"]
    G --> H["持续投入"]
    H --> E
    B -.->|"负反馈"| A
    F -.->|"负反馈"| I["调整方向"]
    I --> A
```

描述说明：
- 主循环展示兴趣培养的增强回路
- 从"开始尝试"到"持续投入"形成正向循环
- 能力提升和正反馈是兴趣加深的核心驱动力
- 虚线箭头展示负反馈时的调整路径
- 用于展示"兴趣是养出来的"这一核心观点
