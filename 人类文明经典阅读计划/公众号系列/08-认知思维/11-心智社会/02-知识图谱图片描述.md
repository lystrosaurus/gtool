# 《心智社会》知识图谱图片描述

本文档包含4张Mermaid知识图谱，用于可视化《心智社会》的核心概念体系。

---

## 图一：心智层级结构图（Tree Diagram）

展示明斯基心智理论中的层级架构，从底层无意识机制到高层意识思维的递进关系。

```mermaid
graph TD
    A["心智社会 Society of Mind"] --> B["意识层 Conscious Mind"]
    A --> C["认知层 Cognitive Mind"]
    A --> D["本能层 Instinctive Mind"]
    
    B --> B1["自我反思"]
    B --> B2["语言表达"]
    B --> B3["抽象推理"]
    
    C --> C1["学习记忆"]
    C --> C2["模式识别"]
    C --> C3["因果推理"]
    
    D --> D1["感知输入"]
    D --> D2["运动控制"]
    D --> D3["情绪反应"]
```

**设计说明**：树形结构，自上而下展现心智的三个层级及其子模块，配色建议从深蓝渐变到浅蓝。

---

## 图二：智能体协作网络图（Network Diagram）

展示不同类型智能体之间的协作、竞争和抑制关系，体现"心智即社会"的核心隐喻。

```mermaid
graph LR
    P1["感知智能体"] --> M1["记忆智能体"]
    P1 --> M2["匹配智能体"]
    M1 --> R1["推理智能体"]
    M2 --> R1
    R1 --> S1["选择智能体"]
    
    E1["情绪智能体"] -.->|"影响"| R1
    E1 -.->|"影响"| S1
    
    S1 -->|"执行"| A1["行动智能体"]
    
    F1["抑制智能体"] -.->|"抑制"| P1
    F1 -.->|"抑制"| M1
    
    C1["批评智能体"] -.->|"反馈"| R1
```

**设计说明**：网状结构，实线表示协作关系，虚线表示影响或抑制关系，中心节点为推理智能体。

---

## 图三：思维过程路径图（Path Diagram）

展示一个具体思维决策过程中，信号如何在不同智能体之间传递和转化。

```mermaid
graph LR
    START(("输入刺激")) --> P["感知处理"]
    P --> M{"模式匹配"}
    M -->|"匹配成功"| R["检索经验"]
    M -->|"匹配失败"| N["新建连接"]
    R --> E["评估选项"]
    N --> E
    E --> C{"冲突检测"}
    C -->|"无冲突"| D["做出决策"]
    C -->|"有冲突"| I["内部协商"]
    I --> D
    D --> ACT(("输出行为"))
```

**设计说明**：从左到右的流程图，菱形节点表示判断分支，圆角矩形表示处理步骤。

---

## 图四：智能体涌现关系图（Graph Diagram）

展示从简单组件到复杂心智能力的涌现过程，体现"整体大于部分之和"的核心思想。

```mermaid
graph TD
    subgraph 基础层
        A1[无意识机制]
        A2[简单反射]
        A3[条件反应]
    end
    
    subgraph 组合层
        B1[感知整合]
        B2[记忆编码]
        B3[情感标记]
    end
    
    subgraph 协调层
        C1[目标设定]
        C2[策略选择]
        C3[自我监控]
    end
    
    subgraph 涌现层
        D1[意识]
        D2[创造力]
        D3[自由意志感]
    end
    
    A1 --> B1
    A2 --> B1
    A2 --> B2
    A3 --> B2
    A3 --> B3
    
    B1 --> C1
    B2 --> C1
    B2 --> C2
    B3 --> C2
    B3 --> C3
    
    C1 --> D1
    C2 --> D2
    C3 --> D3
    
    A1 -.->|"4层涌现"| D1
```

**设计说明**：四层结构的涌现图，使用subgraph分组，从下到上展示从简单机制到高级心智能力的涌现过程。
