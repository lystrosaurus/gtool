# 《超越智商》知识图谱图片描述

> 本文包含 4 张知识图谱 Mermaid 图表，分别展示：理性思维分类树、智力与理性对比图谱、理性决策路径图、认知偏差网络图。

---

## 图一：理性思维分类树

**图表类型**：分类树（Tree Diagram）

**设计说明**：展示理性思维的多层次结构，从基础能力到高级决策的完整分类体系。

```mermaid
graph TD
    A["理性思维体系"] --> B["基础能力层"]
    A --> C["思维工具层"]
    A --> D["决策应用层"]

    B --> B1["概率思维"]
    B --> B2["逻辑推理"]
    B --> B3["科学方法论"]

    C --> C1["证伪态度"]
    C --> C2["贝叶斯更新"]
    C --> C3["反事实思考"]

    D --> D1["决策质量评估"]
    D --> D2["风险收益分析"]
    D --> D3["认知偏差规避"]

    B1 -.支撑.-> C2
    C1 -.保障.-> D1
```

**视觉要点**：
- 三层结构用不同颜色区分：基础层（蓝色）、工具层（绿色）、应用层（橙色）
- 横向虚线箭头标注"支撑"和"保障"关系
- 节点文字精简，适合移动端阅读

---

## 图二：智力与理性对比图谱

**图表类型**：对比图（Comparison Diagram）

**设计说明**：直观展示智力与理性的区别和联系，帮助读者理解"车速 vs 方向盘"的核心比喻。

```mermaid
graph LR
    subgraph 智力 Intelligence
        I1["抽象推理"]
        I2["工作记忆"]
        I3["处理速度"]
        I4["模式识别"]
    end

    subgraph 理性 Rationality
        R1["概率思维"]
        R2["证伪态度"]
        R3["偏差规避"]
        R4["目标连贯性"]
    end

    I1 -.不必然导致.-> R1
    I2 -.不必然导致.-> R3
    I4 -.可能被误用.-> R3

    I1 -.配合.-> R1
    I2 -.配合.-> R2

    style I1 fill:#e3f2fd
    style I2 fill:#e3f2fd
    style I3 fill:#e3f2fd
    style I4 fill:#e3f2fd
    style R1 fill:#fff3e0
    style R2 fill:#fff3e0
    style R3 fill:#fff3e0
    style R4 fill:#fff3e0
```

**视觉要点**：
- 左右两组用不同背景色框区分
- 智力侧用蓝色系，理性侧用橙色系
- 虚线标注"不必然导致"，强调两者的独立性
- 实线标注"配合"，展示理想协作关系

## 图三：理性决策路径图

**图表类型**：流程路径图（Flow Chart）

**设计说明**：展示从信息输入到理性决策的完整路径，以及每一步可能的偏差陷阱。

```mermaid
graph TD
    S["信息输入"] --> F["基础概率评估"]
    F --> A["证据权重分析"]
    A --> B["替代假设生成"]
    B --> T["证伪检验"]
    T --> D["最终决策"]

    F -.跳过.-> D1["忽略基础概率偏差"]
    A -.偏差.-> D2["确认偏误"]
    B -.不足.-> D3["单一假设陷阱"]
    T -.缺失.-> D4["不可证伪信念"]
    D -.影响.-> D5["决策后合理化"]

    D1 -.常见.-> D2
    D3 -.常见.-> D4

    style S fill:#e1f5fe
    style D fill:#c8e6c9
    style D1 fill:#ffebee
    style D2 fill:#ffebee
    style D3 fill:#ffebee
    style D4 fill:#ffebee
```

**视觉要点**：
- 主流程从上到下，用绿色渐变表示正确路径
- 偏差陷阱用红色节点，标注在对应步骤旁边
- 虚线箭头标注"跳过"、"偏差"等风险动作
- 适合竖屏阅读

## 图四：认知偏差网络图

**图表类型**：网络关系图（Network Graph）

**设计说明**：展示导致非理性决策的核心认知偏差及其相互关联，以及对应的"心智程序"解药。

```mermaid
graph TD
    CM["认知吝啬鬼 Cognitive Miser"] --> CB["确认偏误"]
    CM --> AB["锚定效应"]
    CM --> AF["可得性偏差"]

    MG["心智程序缺陷 Mindware Gap"] --> PF["概率忽视"]
    MG --> LR["逻辑谬误"]
    MG --> BN["贝叶斯盲区"]

    MC["心智程序污染 Mindware Contamination"] --> MS["迷信信念"]
    MC --> CT["阴谋论思维"]
    MC --> EC["回音室效应"]

    CB -.解药.-> FA["证伪态度"]
    PF -.解药.-> PS["概率思维"]
    LR -.解药.-> LM["逻辑训练"]
    MS -.解药.-> SM["科学方法论"]

    EC -.强化.-> CB
    CT -.利用.-> AB

    style CM fill:#ffccbc
    style MG fill:#ffccbc
    style MC fill:#ffccbc
    style FA fill:#c8e6c9
    style PS fill:#c8e6c9
    style LM fill:#c8e6c9
    style SM fill:#c8e6c9
```

**视觉要点**：
- 三大根源用橙色节点居中排列
- 具体偏差用白色节点分布在两侧
- 解药用绿色节点，用不同颜色箭头连接
- "强化"和"利用"关系用紫色虚线
- 整体布局呈三层结构：根源 → 偏差 → 解药
