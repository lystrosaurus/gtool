## 图二：五步流程网络图（network）

展示五步流程中各步骤之间的循环关系与反馈机制。

```mermaid
graph LR
    A["目标"] --> B["问题"]
    B --> C["诊断"]
    C --> D["方案"]
    D --> E["执行"]
    E --> F["复盘"]
    F -->|"迭代优化"| A
    F -.->|"新目标"| A
    C -.->|"发现新问题"| B
    D -.->|"方案不可行"| C
```

描述说明：
- 主流程从左到右依次展示五个步骤
- 实线箭头表示主流程推进方向
- 虚线箭头表示反馈回路和逆向跳转
- "复盘"节点回连到"目标"，形成闭环
- 用于展示五步流程的迭代本质

## 图三：个人成长路径图（path）

展示一个人从"无原则"到"原则驱动"的成长路径。

```mermaid
graph TD
    S["起点：凭直觉决策"] --> P1["经历失败"]
    P1 --> P2["反思总结"]
    P2 --> P3["提炼原则"]
    P3 --> P4["验证原则"]
    P4 --> P5{"原则有效?"}
    P5 -->|"是"| P6["固化为习惯"]
    P5 -->|"否"| P2
    P6 --> P7["遇到新挑战"]
    P7 --> P8["调用原则库"]
    P8 --> P9["高效决策"]
    P9 --> P10["持续积累"]
    P10 -->|"原则迭代"| P3
```

描述说明：
- 从"凭直觉决策"的起点出发
- 经过失败-反思-提炼-验证的循环
- 有效原则固化为习惯
- 遇到新挑战时调用原则库
- 形成持续迭代的成长飞轮
