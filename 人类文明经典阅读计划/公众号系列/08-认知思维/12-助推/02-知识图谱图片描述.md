# 《助推》知识图谱图片描述

本文档包含4张Mermaid知识图谱，用于可视化《助推》的核心概念体系。

---

## 图一：选择架构要素树（Tree Diagram）

展示构成选择架构的各个要素及其层级关系。

```mermaid
graph TD
    A["选择架构 Choice Architecture"] --> B["默认选项 Default Options"]
    A --> C["信息框架 Information Framing"]
    A --> D["选项数量 Option Quantity"]
    A --> E["反馈机制 Feedback"]
    A --> F["激励结构 Incentives"]
    
    B --> B1["自动加入 Opt-in"]
    B --> B2["自动退出 Opt-out"]
    
    C --> C1["收益框架 Gain Frame"]
    C --> C2["损失框架 Loss Frame"]
    C --> C3["社会规范 Social Norm"]
    
    D --> D1["精简选项"]
    D --> D2["分类呈现"]
    D --> D3["推荐标记"]
    
    E --> E1["即时反馈"]
    E --> E2["对比反馈"]
    E --> E3["累积反馈"]
    
    F --> F1["经济激励"]
    F --> F2["社会激励"]
    F --> F3["内在激励"]
```

**设计说明**：树形结构，自上而下展示选择架构的五大要素及其子类别，配色建议从深蓝到浅绿的渐变。

## 图二：助推策略网络图（Network Diagram）

展示不同助推策略之间的关联关系和适用场景。

```mermaid
graph LR
    N1["简化流程"] --> P1["降低决策成本"]
    N2["设置默认"] --> P2["利用惯性"]
    N3["提供反馈"] --> P3["增强自我监控"]
    N4["社会比较"] --> P4["激活社会规范"]
    N5["提醒机制"] --> P5["克服遗忘"]
    
    P1 --> O1["提高完成率"]
    P2 --> O2["增加参与度"]
    P3 --> O3["改善行为"]
    P4 --> O4["促进合作"]
    P5 --> O5["减少遗漏"]
    
    N1 -.->|"互补"| N2
    N3 -.->|"互补"| N5
    N4 -.->|"互补"| N3
```

**设计说明**：网状结构，左侧为策略层，中间为机制层，右侧为结果层，虚线表示策略间的互补关系。

## 图三：决策影响路径图（Path Diagram）

展示助推如何通过影响认知路径来改变最终决策。

```mermaid
graph LR
    START(("面临选择")) --> E1["选择环境呈现"]
    E1 --> C1["系统1 快速思考"]
    E1 --> C2["系统2 慢速思考"]
    C1 --> H1["依赖直觉"]
    C1 --> H2["从众倾向"]
    C1 --> H3["惰性选择"]
    C2 --> H4["理性分析"]
    H1 --> D["最终决策"]
    H2 --> D
    H3 --> D
    H4 --> D
    D --> OUT(("行动结果"))
    
    NUDGE["助推干预"] -.->|"影响"| E1
    NUDGE -.->|"引导"| C1
```

**设计说明**：从左到右的决策流程图，展示助推干预如何在不同阶段影响决策路径。

## 图四：自由家长制平衡图（Graph Diagram）

展示自由家长制的核心理念——在尊重自由与引导向善之间寻找平衡。

```mermaid
graph TD
    subgraph 强制手段
        A1["法律法规"]
        A2["禁令"]
        A3["强制要求"]
    end
    
    subgraph 助推手段
        B1["默认选项"]
        B2["信息透明"]
        B3["简化流程"]
        B4["社会规范提示"]
        B5["反馈提醒"]
    end
    
    subgraph 自由放任
        C1["完全自由选择"]
        C2["无任何引导"]
        C3["信息不干预"]
    end
    
    B1 --> D["更好的选择"]
    B2 --> D
    B3 --> D
    B4 --> D
    B5 --> D
    
    A1 --> D
    C1 --> D
    
    D --> E1["自由"]
    D --> E2["福祉"]
    
    A1 -.->|"限制自由"| E1
    C1 -.->|"不保证福祉"| E2
    
    B1 -.->|"保留自由"| E1
    B1 -.->|"提升福祉"| E2
```

**设计说明**：对比展示三种治理手段（强制、助推、放任）与自由和福祉之间的关系，突出助推手段的优势。
