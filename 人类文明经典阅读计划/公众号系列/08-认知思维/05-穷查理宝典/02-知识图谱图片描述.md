# 《穷查理宝典》知识图谱图片描述

> 本文包含 4 张知识图谱 Mermaid 图表，分别展示：多元思维模型分类树、芒格思想人物图谱、跨学科决策路径图、误判心理学网络图。

---

## 图一：多元思维模型分类树

**图表类型**：分类树（Tree Diagram）

**设计说明**：展示芒格多元思维模型的学科分类和核心概念，按学科领域分层呈现。

```mermaid
graph TD
    A["多元思维模型"] --> B["数学模型"]
    A --> C["自然科学模型"]
    A --> D["社会科学模型"]
    A --> E["人文思维模型"]

    B --> B1["复利效应"]
    B --> B2["概率与统计"]
    B --> B3["决策树理论"]

    C --> C1["物理学临界质量"]
    C --> C2["生物学进化论"]
    C --> C3["化学自催化"]

    D --> D1["经济学规模效应"]
    D --> D2["心理学认知偏差"]
    D --> D3["社会学激励机制"]

    E --> E1["逆向思维"]
    E --> E2["哲学第一性原理"]
    E --> E3["历史周期律"]

    B2 -.应用于.-> D2
    C2 -.类比.-> D1
    E1 -.配合.-> B3
```

**视觉要点**：
- 四个学科领域用不同颜色区分：数学（蓝）、科学（绿）、社会（橙）、人文（紫）
- 跨学科关联用虚线箭头标注
- 每个学科 3 个核心概念，保持对称布局

## 图二：芒格思想人物图谱

**图表类型**：人物关系图（Network Graph）

**设计说明**：展示与芒格思想相关的关键人物及其理论贡献的关联网络。

```mermaid
graph LR
    M["查理·芒格 Charlie Munger"] --> W["巴菲特 Warren Buffett"]
    M --> P["多元思维模型"]
    M --> R["逆向思维"]
    M --> Y["误判心理学25条"]

    W --> V["价值投资理念"]

    P --> F["富兰克林 Benjamin Franklin"]
    P --> E["爱因斯坦 Einstein"]

    R --> J["雅各比 Jacobi 数学家"]
    J -.名言.-> R

    Y --> K["卡尼曼 Kahneman"]
    Y --> T["特沃斯基 Tversky"]
    K --> T

    Y --> C["西奥迪尼 Cialdini"]
    C -.影响力六原则.-> Y

    style M fill:#fff3e0
    style W fill:#e8f5e9
    style F fill:#e3f2fd
    style J fill:#e3f2fd
    style K fill:#fce4ec
    style T fill:#fce4ec
    style C fill:#fce4ec
```

**视觉要点**：
- 芒格居中，左右分支分别展示投资关系和思想渊源
- 人物节点用圆形，概念节点用矩形
- 不同学派用不同颜色区分：投资（绿）、数学（蓝）、心理学（粉）
- 标注关键名言引用关系

## 图三：跨学科交叉验证决策路径图

**图表类型**：流程路径图（Flow Chart）

**设计说明**：展示芒格式的跨学科决策流程，从问题定义到多模型验证的完整路径。

```mermaid
graph TD
    P["定义问题"] --> M1["数学模型分析"]
    P --> M2["科学模型分析"]
    P --> M3["社会模型分析"]
    P --> M4["人文模型分析"]

    M1 --> C1["数学结论"]
    M2 --> C2["科学结论"]
    M3 --> C3["社会结论"]
    M4 --> C4["人文结论"]

    C1 --> V{"结论一致?"}
    C2 --> V
    C3 --> V
    C4 --> V

    V -->|"一致"| D["高信心决策"]
    V -->|"不一致"| R["深入分析差异原因"]

    R --> N["寻找额外模型"]
    N --> V

    D --> A["执行决策"]
    A --> F["复盘验证"]

    style P fill:#e1f5fe
    style D fill:#c8e6c9
    style R fill:#fff3e0
    style A fill:#c8e6c9
```

**视觉要点**：
- 问题定义到四个模型分析用并行结构
- 结论汇聚到判断节点（菱形）
- 不一致路径用橙色标注，形成闭环
- 最终决策用绿色表示高信心状态

## 图四：误判心理学 25 条网络图

**图表类型**：网络关系图（Mind Map Style）

**设计说明**：将 25 条误判心理学按功能分组，展示它们之间的关联和叠加效应。

```mermaid
graph TD
    subgraph 感知偏差
        L1["1.奖励超级反应倾向"]
        L2["2.喜爱/热爱倾向"]
        L3["3.讨厌/憎恨倾向"]
        L4["4.避免不一致性倾向"]
    end

    subgraph 社会偏差
        S1["5.社会认同倾向"]
        S2["6.权威错误影响倾向"]
        S3["7.剥夺超级反应倾向"]
        S4["8.自视过高倾向"]
    end

    subgraph 决策偏差
        D1["9.被剥夺超级反应倾向"]
        D2["10.避免怀疑倾向"]
        D3["11.简单心理否认倾向"]
        D4["12.压力影响倾向"]
    end

    L1 -.驱动.-> S1
    S2 -.强化.-> D1
    L4 -.固化.-> D2
    S4 -.导致.-> D3

    style L1 fill:#ffebee
    style L2 fill:#ffebee
    style L3 fill:#ffebee
    style L4 fill:#ffebee
    style S1 fill:#fff3e0
    style S2 fill:#fff3e0
    style S3 fill:#fff3e0
    style S4 fill:#fff3e0
    style D1 fill:#fce4ec
    style D2 fill:#fce4ec
    style D3 fill:#fce4ec
    style D4 fill:#fce4ec
```

**视觉要点**：
- 三组偏差用不同颜色 subgraph 框区分
- 跨组关联用虚线箭头标注"驱动"、"强化"等关系
- 展示偏差之间的叠加效应（多个偏差同时作用时危害更大）
- 实际使用时可展示全部 25 条，此处选取代表性的 12 条
