# 《贪婪的大脑》知识图谱图片描述

> 本文包含 4 张知识图谱 Mermaid 图表，分别展示：意识机制分类树、核心人物关系图谱、思想工厂运作路径图、认知偏差网络图。

## 图一：意识机制分类树

**图表类型**：分类树（Tree Diagram）

**设计说明**：展示意识的多层次结构，从物理基础到主观体验的完整分类体系。

```mermaid
graph TD
    A["意识机制体系"] --> B["物理基础层"]
    A --> C["信息处理层"]
    A --> D["主观体验层"]

    B --> B1["神经元放电"]
    B --> B2["突触传递"]
    B --> B3["脑区协同"]

    C --> C1["感觉输入"]
    C --> C2["模式识别"]
    C --> C3["记忆整合"]

    D --> D1["自我觉察"]
    D --> D2["注意力聚焦"]
    D --> D3["意识流"]

    B3 -.影响.-> C1
    C3 -.涌现.-> D1
```

**视觉要点**：
- 三层结构用不同颜色区分：物理层（冷蓝色）、处理层（绿色）、体验层（暖橙色）
- 横向箭头用虚线标注"影响"和"涌现"关系
- 适合横屏阅读，节点文字控制在 6 字以内

## 图三：思想工厂运作路径图

**图表类型**：流程路径图（Flow Chart）

**设计说明**：可视化"思想工厂"从原材料输入到意识产出的完整流水线。

```mermaid
graph TD
    S["感觉输入原材料"] --> F["过滤机制"]
    F --> P["模式识别加工"]
    P --> M["记忆数据库调用"]
    M --> N["叙事引擎编故事"]
    N --> C["意识产品产出"]

    F -.丢弃 90%.-> X["无意识处理"]
    N -.残次品.-> H["幻觉/错觉"]
    C -.反馈.-> F

    H -.被误认为真实.-> C

    style S fill:#e1f5fe
    style C fill:#fff3e0
    style H fill:#ffebee
    style X fill:#f5f5f5
```

**视觉要点**：
- 主流程用实线箭头从左到右排列
- 旁支路径用虚线，标注关键数据（如"丢弃 90%"）
- 反馈回路用弯曲箭头表示循环特性
- 用不同底色区分阶段：输入（蓝）、产出（橙）、残次品（红）、无意识（灰）

## 图四：认知偏差网络图

**图表类型**：网络关系图（Mind Map Style）

**设计说明**：展示模式饥饿导致的各类认知偏差及其相互关联。

```mermaid
graph TD
    PH["模式饥饿 Pattern Hunger"] --> CA["确认偏误"]
    PH --> AP["空想性错视"]
    PH --> SC["过度因果推理"]
    PH --> CL["聚类错觉"]

    CA --> EC["回音室效应"]
    AP --> PS["人脸幻觉"]
    SC --> SU["阴谋论思维"]
    CL --> GF["赌徒谬误"]

    EC -.强化.-> PH
    SU -.利用.-> SC

    PH -.根源.-> CA
    PH -.根源.-> AP
    PH -.根源.-> SC
    PH -.根源.-> CL
```

**视觉要点**：
- 中心节点"模式饥饿"用大圆或特殊形状突出
- 一级偏差用矩形，二级效应用圆角矩形
- "强化"和"利用"关系用不同颜色虚线标注
- 整体布局呈放射状，适合竖屏移动端阅读
