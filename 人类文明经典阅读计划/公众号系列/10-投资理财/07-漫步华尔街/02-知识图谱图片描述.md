# 知识图谱图片描述

本文档描述《漫步华尔街》知识图谱中使用的4张Mermaid图，用于生成配套图片。

## 图一：投资理论体系树状图

展示书中涉及的投资理论流派和核心概念层级。

```mermaid
graph TD
    A["漫步华尔街"] --> B["有效市场假说"]
    A --> C["投资分析方法"]
    A --> D["资产配置理论"]
    A --> E["行为金融学"]

    B --> B1["弱式有效市场"]
    B --> B2["半强式有效市场"]
    B --> B3["强式有效市场"]

    C --> C1["技术分析"]
    C --> C2["基本面分析"]
    C --> C3["指数化投资"]

    D --> D1["生命周期投资法"]
    D --> D2["风险收益平衡"]
    D --> D3["分散化投资"]

    E --> E1["羊群效应"]
    E --> E2["过度自信偏差"]
    E --> E3["损失厌恶"]
```
