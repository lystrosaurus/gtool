## 图一：五种护城河来源树状图

**用途**：系统展示企业护城河的五种主要来源及其特征

**Mermaid 代码**：

```mermaid
graph TD
    A["企业护城河五大来源"] --> B["无形资产"]
    A --> C["转换成本"]
    A --> D["网络效应"]
    A --> E["成本优势"]
    A --> F["有效规模"]

    B --> B1["品牌溢价"]
    B --> B2["专利保护"]
    B --> B3["监管牌照"]

    C --> C1["数据迁移成本"]
    C --> C2["员工培训成本"]
    C --> C3["业务中断风险"]

    D --> D1["用户越多价值越大"]
    D --> D2["自我强化的网络"]
    D --> D3["赢家通吃效应"]

    E --> E1["规模经济"]
    E --> E2["独特资源渠道"]
    E --> E3["高效运营流程"]

    F --> F1["市场容量有限"]
    F --> F2["新进入者无利可图"]
    F --> F3["自然垄断特征"]
```

**布局说明**：根节点居中顶部，五大护城河均匀展开，每个来源下三个具体表现形式。

## 图二：护城河评估决策路径图

**用途**：展示评估一家公司护城河宽度的分析决策流程

**Mermaid 代码**：

```mermaid
flowchart TD
    A["发现目标公司"] --> B{"是否有无形资产护城河?"}
    B -->|"品牌|专利|牌照"| C["记录无形资产优势"]
    B -->|"否"| D{"用户切换成本高吗?"}
    C --> D
    D -->|"是"| E["记录转换成本优势"]
    D -->|"否"| F{"是否存在网络效应?"}
    E --> F
    F -->|"是"| G["记录网络效应优势"]
    F -->|"否"| H{"是否有成本优势?"}
    G --> H
    H -->|"是"| I["记录成本优势"]
    H -->|"否"| J{"市场是否有效规模?"}
    I --> J
    J -->|"是"| K["记录有效规模优势"]
    J -->|"否"| L["无显著护城河"]
    K --> M["统计护城河数量"]
    M --> N{"护城河数量大于等于2?"}
    N -->|"是"| O["宽广护城河"]
    N -->|"否"| P["狭窄护城河或无护城河"]
```

**布局说明**：自上而下的评估流程，逐一检验五种护城河，最终汇总判断宽度。

## 图三：护城河与企业回报关系网络图

**用途**：展示护城河、竞争、利润和长期回报之间的因果网络

**Mermaid 代码**：

```mermaid
graph TB
    A["宽广护城河"] -->|"阻止"| B["新竞争者进入"]
    A -->|"保护"| C["超额利润率"]
    C -->|"吸引"| D["潜在竞争者"]
    B -->|"削弱"| D
    C -->|"产生"| E["自由现金流"]
    E -->|"用于"| F["再投资"]
    F -->|"加宽"| A
    E -->|"用于"| G["股东回报"]
    G --> G1["分红"]
    G --> G2["回购"]
    C -->|"持续"| H["长期高资本回报率"]
    H -->|"带来"| I["股东长期超额收益"]

    subgraph 护城河来源
        A1["无形资产"]
        A2["转换成本"]
        A3["网络效应"]
        A4["成本优势"]
        A5["有效规模"]
    end

    A1 -->|"构成"| A
    A2 -->|"构成"| A
    A3 -->|"构成"| A
    A4 -->|"构成"| A
    A5 -->|"构成"| A
```

**布局说明**：展示护城河保护利润、利润再投资加宽护城河的正向循环网络。

## 图四：真护城河与伪护城河对比图

**用途**：对比真正的护城河与常见伪护城河的本质差异

**Mermaid 代码**：

```mermaid
graph TB
    subgraph 真护城河
        A1["品牌溢价：消费者愿意付更多"]
        A2["转换成本：切换代价极其高昂"]
        A3["网络效应：用户增长自我强化"]
        A4["成本优势：结构性的低成本"]
        A5["有效规模：市场容纳有限玩家"]
    end

    subgraph 伪护城河
        B1["优质产品：容易被模仿超越"]
        B2["高市场份额：可能昙花一现"]
        B3["优秀管理层：人才会流动"]
        B4["热门概念：风口过后回归平庸"]
        B5["短期高利润：竞争很快涌入"]
    end

    A1 -.->|"结构性优势"| B1
    A2 -.->|"结构性优势"| B2
    A3 -.->|"结构性优势"| B3
    A4 -.->|"结构性优势"| B4
    A5 -.->|"结构性优势"| B5

    C["护城河判断标准：能否阻止竞争者？"] -.->|"检验"| A1
    C -.->|"检验"| A2
```

**布局说明**：左右对比结构，真护城河具有结构性特征，伪护城河多为暂时性现象。
