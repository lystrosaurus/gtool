# 知识图谱图片描述

本文档描述《手把手教你读财报》知识图谱中使用的4张Mermaid图，用于生成配套图片。

## 图一：三大报表知识体系树状图

展示财务报表分析的核心知识框架。

```mermaid
graph TD
    A["财报分析体系"] --> B["资产负债表"]
    A --> C["利润表"]
    A --> D["现金流量表"]
    A --> E["财报排雷指南"]

    B --> B1["资产类科目"]
    B --> B2["负债类科目"]
    B --> B3["所有者权益"]

    C --> C1["营业收入"]
    C --> C2["成本费用"]
    C --> C3["净利润"]

    D --> D1["经营活动现金流"]
    D --> D2["投资活动现金流"]
    D --> D3["筹资活动现金流"]

    E --> E1["应收账款异常"]
    E --> E2["存货异常"]
    E --> E3["现金流与利润背离"]
```

graph LR

## 图四：财报健康度诊断流程图

    H --> J["小于1：警惕"]
    J --> K["第三步：检查异常科目"]

    M --> O
    N --> O
    O --> P["综合判断"]

    P --> Q["纳入投资池"]
