## 图一：财务自由目标层级图（树状图）

展示从基础财务安全到终极财务自由的目标递进关系。

```mermaid
graph TD
    A["财务自由之路"]
    A --> B["财务安全"]
    A --> C["财务独立"]
    A --> D["财务自由"]

    B --> B1["覆盖基本生活开支"]
    B --> B2["建立应急基金"]
    B --> B3["消除高息债务"]

    C --> C1["被动收入覆盖生活费"]
    C --> C2["拥有多元化投资组合"]
    C --> C3["不再为钱而工作"]

    D --> D1["被动收入远超支出"]
    D --> D2["时间完全自主支配"]
    D --> D3["实现人生终极目标"]

    style A fill:#1a5276,color:#fff
    style B fill:#2e86c1,color:#fff
    style C fill:#27ae60,color:#fff
    style D fill:#f39c12,color:#000
```

**图一说明**：这棵树展示了财务自由的三个阶段，每个阶段都有明确的可量化标准。从底层的财务安全到中层的财务独立，再到顶层的财务自由，每一层都是下一层的基础。
