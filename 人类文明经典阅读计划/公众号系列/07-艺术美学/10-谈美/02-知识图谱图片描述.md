# 02-知识图谱图片描述

## ◆ 图片一：人生的三种态度（分类树）

> **图表说明**：此图展示了朱光潜《谈美》中对人生基本态度的分类，帮助读者理解"美感态度"与"实用态度"、"科学态度"的本质区别。

```mermaid
graph TD
    A["人生的三种基本态度"]
    A --> B["实用态度"]
    A --> C["科学态度"]
    A --> D["美感态度"]
    
    B --> B1["核心: 善"]
    B --> B2["目的: 满足实际需求"]
    B --> B3["典型: 商人看古松"]
    
    C --> C1["核心: 真"]
    C --> C2["目的: 探索客观规律"]
    C --> C3["典型: 科学家看古松"]
    
    D --> D1["核心: 美"]
    D --> D2["目的: 无所为而为"]
    D --> D3["典型: 画家看古松"]
    
    style D fill:#f9f,stroke:#333,stroke-width:2px
```

**排版提示**：在公众号编辑器中插入上述 Mermaid 渲染后的图片，建议配色以淡雅的莫兰迪色为主，突出"美感态度"分支。

## ◆ 图片二：美学核心人物图谱（人物关系图）

> **图表说明**：梳理了影响朱光潜美学思想的中外关键人物，以及他们在《谈美》中的角色定位。

```mermaid
graph LR

    Zhu --> Book[谈美<br/>1932年出版]

    style Zhu fill:#f9f,stroke:#333,stroke-width:4px

```

**排版提示**：人物图谱建议横向排版，突出朱光潜作为中西美学桥梁的核心地位。

## ◆ 图片三：从功利到自由的审美路径（流程图）

> **图表说明**：展示了如何通过"心理距离"的建立，从日常的功利心态走向自由的审美体验。

```mermaid
flowchart LR
    Start[日常功利心态] --> Step1[暂停实用目的]
    Step1 --> Step2[拉开心理距离]
    Step2 --> Step3[专注于事物本身]
    Step3 --> Step4[产生直觉意象]
    Step4 --> End[获得美感体验]
    
    Step2 -.->|距离太远| TooFar[无法理解]
    Step2 -.->|距离太近| TooClose[陷入功利]
    Step2 -.->|距离适中| JustRight[最佳审美距离]
    
    style End fill:#dfd,stroke:#333,stroke-width:2px
    style JustRight fill:#ffd,stroke:#333,stroke-width:2px
```

**排版提示**：此图重点突出"距离适中"这一最佳审美状态，可用高亮色块标注。
