# 行动挑战：读完《霍乱时期的爱情》后，请做这五件事

◆ 阅读只是开始。行动才是答案。

很多人读完一本书，合上书页，就结束了。

但经典之所以为经典，是因为它能改变你的生活。

读完《霍乱时期的爱情》，我邀请你完成以下五个挑战。

不需要一天完成。可以用一周、一个月，甚至一年。

但请开始。

◆◇ 挑战一：给你生命中重要的人写一封信

弗洛伦蒂诺给费尔明娜写了七百多封信。

你不需要写七百封。一封就够。

这封信可以写给父母。写给伴侣。写给一个曾经重要、但已经失去联系的朋友。

不要用微信。不要用邮件。用纸和笔。

写下你最想说的话。然后，寄出去。或者，亲手交给对方。

○ 行动步骤

1. 准备一张信纸和一支笔
2. 想好你要写给谁
3. 写下你的真实感受，不需要修饰
4. 折叠好，装入信封
5. 寄出或亲手交付

◆ 挑战二：审视你对爱情的定义

马尔克斯告诉我们：爱情没有标准答案。

但你可能一直被某种"标准"束缚着。

今天，请你拿出纸笔，回答以下三个问题：

1. 我认为什么是真正的爱情？
2. 这个定义是谁给我的？父母？社会？朋友？还是我自己？
3. 如果抛开所有人的看法，我自己认为的爱情是什么？

○ 行动步骤

1. 找一个安静的地方
2. 准备纸笔
3. 诚实回答上述三个问题
4. 写完后，放在一个你能经常看到的地方

● 挑战三：设定一个"五十三年"的目标

弗洛伦蒂诺用五十三年证明了一件事：坚持的力量。

你不需要等五十三年。但你可以设定一个长期目标。

这个目标可以是：

- 掌握一门新技能
- 完成一个搁置已久的项目
- 改善一段关系
- 改变一个坏习惯

关键是：它必须是一个值得你用时间去兑现的承诺。

○ 行动步骤

1. 想一件你一直想做但没做的事
2. 把它写下来
3. 设定一个时间节点
4. 从今天开始，每天为它做一件小事

◇ 挑战四：和身边的人聊一次"衰老"

书的结尾，弗洛伦蒂诺和费尔明娜都已白发苍苍。

我们很少谈论衰老。我们害怕它。

但马尔克斯告诉我们：衰老不是终点。而是另一种开始。

请你和一个你信任的人，聊一次关于"衰老"的话题。

可以聊：你害怕变老吗？你觉得老了以后，最重要的事情是什么？你希望老了以后，身边有谁？

○ 行动步骤

1. 找一个你信任的人
2. 选择一个放松的环境
3. 坦诚地聊一次关于衰老的话题
4. 听完对方的想法后，写下你最大的感受

◆ 挑战五：在接下来的一周，做一次"不求回报"的付出

弗洛伦蒂诺的等待，本质上是一种不求回报的付出。

他不确定费尔明娜最终会不会接受他。但他依然等了。

在接下来的一周，请做一件不求回报的事。

可以是为家人做一顿饭。可以是为同事分担一项工作。可以是为陌生人做一次小小的善意之举。

不期待感谢。不期待回报。

只是因为，你想做。

○ 行动步骤

1. 想好你要做什么
2. 去做
3. 做完之后，不要告诉任何人
4. 在心里，默默感受那种"付出"的力量

◆◇ 最后的挑战：重读一遍

所有挑战完成后，请重读一遍《霍乱时期的爱情》。

你会发现，第二次读和第一次读，感受完全不同。

因为，你已经不是从前的你了。

你等过。你写过。你付出过。你思考过。

你，已经走在弗洛伦蒂诺走过的路上。

哪怕只是其中一小段。

但那也足够了。
