# 知识图谱图片描述

## 图一：故事结构树状图

**图表类型**：tree（树状图）

**用途**：展示《老人与海》的核心叙事结构

**描述**：以"老人与海"为根节点，向下展开为三个叙事阶段：出海前、搏斗中、归航后。每个阶段再展开为关键事件和象征意义。整体呈自上而下的树状结构，体现故事的时间推进和主题深化。

**配色建议**：根节点使用深蓝色（#003366），象征海洋。三个主分支分别使用浅蓝、金黄、暗红，代表出发、抗争与悲壮。

**Mermaid 代码**：

```mermaid
graph TD
    Story[老人与海]
    Story --> Departure[出海前]
    Story --> Battle[搏斗中]
    Story --> Return[归航后]
    Departure --> D1[八十四天未捕到鱼]
    Departure --> D2[被嘲笑 被孤立]
    Departure --> D3[象征: 困境中的坚持]
    Battle --> B1[钓到巨大马林鱼]
    Battle --> B2[三天三夜的对抗]
    Battle --> B3[杀死马林鱼]
    Battle --> B4[象征: 人与自然的较量]
    Return --> R1[鲨鱼群袭击]
    Return --> R2[战斗到最后一刻]
    Return --> R3[只剩骨架]
    Return --> R4[象征: 精神的不朽]
```

## 图二：人物精神力量网络图

**图表类型**：network（网络关系图）

**用途**：呈现圣地亚哥精神世界的多维构成

**描述**：以"圣地亚哥"为核心节点，向外连接五种精神力量：尊严、毅力、孤独、信念、勇气。每种精神力量再连接到具体行为表现，形成网状结构，展示人物内心的丰富层次。

**配色建议**：圣地亚哥使用深褐色（#5C4033），象征沉稳与沧桑。五种精神力量使用不同色调，形成视觉区分。

**Mermaid 代码**：

```mermaid
graph LR
    S[圣地亚哥]
    S --> Dignity[尊严]
    S --> Perseverance[毅力]
    S --> Loneliness[孤独]
    S --> Faith[信念]
    S --> Courage[勇气]
    Dignity --> D1[独自出海 不乞求同情]
    Dignity --> D2[与马林鱼平等对话]
    Perseverance --> P1[三天三夜不眠不休]
    Perseverance --> P2[双手流血仍握紧钓索]
    Loneliness --> L1[没有同伴 只有大海]
    Loneliness --> L2[与星星和飞鸟说话]
    Faith --> F1[相信今天会不一样]
    Faith --> F2[相信自己的技术]
    Courage --> C1[面对鲨鱼群不退缩]
    Courage --> C2[用尽一切方式战斗]
```

## 图三：抗争路径图

**图表类型**：path（路径图）

**用途**：梳理圣地亚哥从出海到归航的完整抗争路径

**描述**：从左至右的路径，标记七个关键节点。每个节点代表一次挑战与回应。路径线由细变粗再变细，象征力量的积蓄、爆发与消耗。最终节点虽指向"失败"的结果，但标注"精神胜利"的反转。

**配色建议**：路径使用渐变色，从深蓝到暗红再到灰色，象征从出发到战斗再到残骸的过程。关键节点用圆形标记，配以简短有力的文字。

**Mermaid 代码**：

```mermaid
graph LR
    P1[出发: 黑暗中的信念] --> P2[上钩: 巨大的马林鱼]
    P2 --> P3[坚持: 三天三夜]
    P3 --> P4[胜利: 杀死马林鱼]
    P4 --> P5[危机: 鲨鱼来袭]
    P5 --> P6[抗争: 战斗到最后]
    P6 --> P7[归航: 骨架与尊严]
    P1 -. 开始 .-> P2
    P2 -. 考验 .-> P3
    P3 -. 极限 .-> P4
    P4 -. 转折 .-> P5
    P5 -. 毁灭 .-> P6
    P6 -. 不败 .-> P7
```

## 图四：冰山理论对照图

**图表类型**：graph（对照图）

**用途**：揭示海明威"冰山理论"在本书中的体现

**描述**：上下对比结构。上方为"水面之上：文本直接呈现的内容"，列出具体情节。下方为"水面之下：深层含义与象征"，列出对应的隐喻。中间用一条波浪线分隔，象征水面。左右对应关系用虚线连接。

**配色建议**：水上部分使用浅蓝色背景，水下部分使用深蓝色背景。对应关系用金色虚线连接，突出冰山理论的核心概念。

**Mermaid 代码**：

```mermaid
graph TB
    subgraph Above[水面之上: 文本直接呈现]
        A1[老人八十四天没捕到鱼]
        A2[与马林鱼搏斗三天三夜]
        A3[用鱼叉和刀对抗鲨鱼]
        A4[最终带回一副骨架]
        A5[小男孩决定重新跟着他]
    end
    subgraph Below[水面之下: 深层含义与象征]
        B1[人生困境中的坚守]
        B2[人与命运的终极对抗]
        B3[面对毁灭时的不屈抗争]
        B4[精神胜利超越物质结果]
        B5[传承: 精神的延续]
    end
    A1 -.- B1
    A2 -.- B2
    A3 -.- B3
    A4 -.- B4
    A5 -.- B5
```
