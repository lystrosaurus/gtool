# 行动挑战：读完《老人与海》后，请做这五件事

◆ 海明威不需要你感动。他需要你行动。

《老人与海》是一本很短的书。

但它的力量，不在于字数。而在于它能否点燃你内心的那团火。

读完之后，请完成以下五个挑战。

它们不容易。但正因如此，它们才值得做。

◆◇ 挑战一：完成一件你一直逃避的事

圣地亚哥在八十四天没有捕到鱼之后，选择了继续出海。

你呢？

有什么事，你一直在逃避？

一场艰难的对话。一次重要的汇报。一个搁置已久的决定。

今天，面对它。

不需要等到"完美的时机"。完美的时机永远不会来。

像圣地亚哥一样，在黑暗中醒来。收拾好你的"渔具"。然后，出发。

○ 行动步骤

1. 写下你一直逃避的那件事
2. 分析你逃避的原因
3. 告诉自己：今天，我面对它
4. 立刻开始行动。不需要准备。不需要等待。

◆ 挑战二：在极端疲惫时，再多坚持十分钟

圣地亚哥在三天三夜的搏斗中，无数次想要放弃。

但他没有。

他告诉自己：再坚持一会儿。

你的生活中，也有这样的时刻。

加班到深夜。身体疲惫。精神崩溃。但你还有最后一点工作没完成。

这时候，告诉自己：再多坚持十分钟。

不是十小时。十分钟。

十分钟，不会要了你的命。但十分钟，会让你发现自己比想象中更强。

○ 行动步骤

1. 下次你感到极度疲惫时，不要立刻放弃
2. 设定一个十分钟的计时器
3. 在这十分钟里，尽全力继续
4. 十分钟后，再决定是继续还是休息

● 挑战三：主动向一个"对手"表达尊重

圣地亚哥尊重他的马林鱼。

你尊重你的对手吗？

职场上的竞争对手。生活中的困难。那些让你头疼的人。

试着向他们表达一次尊重。

不是认输。不是示弱。而是一种强者的姿态：我看到了你的力量。我尊重你。然后，我会继续战斗。

○ 行动步骤

1. 想一个你的"对手"
2. 写下一段话，表达你对它的尊重
3. 如果可以，把这段话告诉对方
4. 如果不行，在心里完成这个仪式

◇ 挑战四：独处一天，不看手机

圣地亚哥在海上，是绝对孤独的。

没有手机。没有社交网络。没有信息轰炸。

只有他自己。和大海。

你能做到吗？

选择一个休息日。关掉手机。独处一天。

你会感到焦虑。会感到无聊。会感到恐惧。

但熬过去之后，你会感受到一种久违的力量。

那种力量，来自你自己。

○ 行动步骤

1. 选择一个休息日
2. 提前告知家人朋友你会失联一天
3. 关掉手机，或者把手机锁在抽屉里
4. 做你想做的事：读书、散步、思考、发呆
5. 一天结束后，写下你的感受

◆ 挑战五：写下你的"骨架"，然后继续出海

圣地亚哥带回了一副骨架。

但你也有属于自己的"骨架"。

那些失败的项目。那些破碎的关系。那些未完成的梦想。

不要隐藏它们。把它们写下来。

然后，在每一副"骨架"旁边，写下你从中学到的东西。

最后，在纸的最下方，写一句话：

"我还会继续出海。"

○ 行动步骤

1. 准备一张纸
2. 写下你所有的"骨架"
3. 在每一个旁边，写下你学到的东西
4. 在纸的最下方，写下"我还会继续出海"
5. 把这张纸贴在你能看到的地方

◆◇ 最后的挑战：成为别人的"马诺林"

马诺林是圣地亚哥精神的传承者。

你也可以成为别人的传承者。

找到一个你欣赏的人。一个在困境中依然坚持的人。一个你愿意追随的人。

告诉他："我想跟你一起出海。"

这不是表白。这是传承。

圣地亚哥的精神，通过马诺林延续了下去。

你的精神，也可以通过你选择的那个人，延续下去。

去找到他。然后，告诉他。
