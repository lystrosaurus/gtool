# 《挪威的森林》知识图谱图片描述

## 图一：主要人物关系树形图

**图表类型：** tree graph

**描述：** 以渡边为中心，展示小说中主要人物的关系网络，标注每个人物的命运走向和象征意义。

```mermaid
graph TD
    A["渡边彻（主人公，在生死之间徘徊的年轻人）"] --> B["直子（木月的恋人，被死亡吞噬的灵魂）"]
    A --> C["绿子（活泼坚韧的女孩，生命力的象征）"]
    A --> D["木月（渡边好友，17岁自杀，死亡的起点）"]
    A --> E["玲子（疗养院室友，钢琴家，过来人的守护）"]
    A --> F["永泽（渡边的学长，精英但冷漠的虚无主义者）"]
    B --> G["初美（永泽的女友，温柔但悲剧的女性）"]

    D -. 死亡阴影 .-> B
    C -. 生命之光 .-> A
    E -. 温柔引导 .-> B
    F -. 虚无对照 .-> A

    style A fill:#c4d9f9,stroke:#333,stroke-width:2px
    style B fill:#a0a0d0,stroke:#333
    style C fill:#d0f0a0,stroke:#333
    style D fill:#555,stroke:#333,color:#fff
```

## 图三：生死主题网络图

```mermaid
graph TD
    A["死亡与失去"] --> A1["木月自杀\n死亡的起点"]
    A --> A2["直子自杀\n被死亡吞噬"]
    A --> A3["初美之死\n温柔的毁灭"]

    A -. 阴影笼罩 .-> C
    B -. 光芒穿透 .-> C
```

## 图四：人物象征对比图

**图表类型：** graph with cross-connections

**描述：** 对比小说中代表"死亡/过去"与"生命/未来"的人物群像，展示两者之间的张力。

```mermaid
graph TD
    A["死亡与过去"] --> A1["木月：17岁自杀\n纯粹的死亡"]
    A --> A2["直子：无法走出创伤\n缓慢的坠落"]
    A --> A3["初美：温柔被摧毁\n无声的毁灭"]

    B --> B3["渡边：在迷茫中前行\n成长的过程"]

    A1 -. 对立与张力 .-> B1
    A2 -. 对立与张力 .-> B2
    A3 -. 对立与张力 .-> B3

    A -. 渡边的拉扯 .-> C["渡边彻\n在两者之间"]
    B -. 渡边的拉扯 .-> C

    style A fill:#7070a0,stroke:#333,stroke-width:2px
```
