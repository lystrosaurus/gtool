**图表类型：** tree graph

**描述：** 以孙玉厚一家为核心，展示主要人物的血缘关系和社会关系，标注每个人的命运走向。

```mermaid
graph TD
    A["孙玉厚（父亲，老农民）"] --> B["孙少安（长子，砖厂创业者）"]
    A --> C["孙少平（次子，煤矿工人）"]
    A --> D["孙兰香（女儿，大学生）"]
    A --> E["孙兰花（长女，嫁王满银）"]
    B --> F["贺秀莲（妻子，陪少安吃苦）"]
    C --> G["田晓霞（恋人，省报记者，牺牲）"]
    D --> H["吴仲平（男友，大学生）"]
    E --> I["王满银（丈夫，不务正业）"]

    J["田福堂（村支书，润叶父亲）"] --> K["田润叶（少安青梅竹马，嫁李向前）"]
    J --> L["田润生（与郝红梅结合）"]
    M["田福军（县领导，晓霞父亲）"] --> G

    style A fill:#f5e6d0,stroke:#333,stroke-width:2px
```

```mermaid
graph LR
    A["共同起点\n贫寒农家"] --> B["少安：辍学务农"]
    A --> C["少平：高中毕业"]

    B --> D["办砖厂失败\n负债累累"]
    D --> E["再次创业\n砖厂成功"]
    E --> F["成为致富带头人\n改变双水村"]

    C --> G["城市揽工汉\n饱尝艰辛"]

    H --> I["精神追求不懈\n读书思考"]

    F -. 扎根土地 .-> J["平凡中的伟大"]
    I -. 走向远方 .-> J

    style A fill:#f9d0c4,stroke:#333,stroke-width:2px
    style J fill:#d0f9c4,stroke:#333,stroke-width:2px
```

```mermaid
    C --> C2["理想与生活的碰撞"]
```
