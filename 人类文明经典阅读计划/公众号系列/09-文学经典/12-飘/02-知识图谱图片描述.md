# 知识图谱图片描述：《飘》

## 图一：人物关系树状图（Tree Diagram）

展示《飘》中核心人物及其家族、情感关系层级。

```mermaid
graph TD
    A["南方种植园社会<br/>塔拉庄园"]
    A --> B["奥哈拉家族"]
    A --> C["汉密尔顿家族"]
    A --> D["巴特勒家族"]
    B --> E["斯嘉丽<br/>核心人物"]
    B --> F["卡琳<br/>妹妹"]
    B --> G["苏埃伦<br/>妹妹"]
    B --> H["杰拉尔德<br/>父亲"]
    B --> I["埃伦<br/>母亲"]
    E --> J["查尔斯<br/>第一任丈夫"]
    E --> K["弗兰克<br/>第二任丈夫"]
    E --> L["瑞德<br/>第三任丈夫"]
    E -.执念.-> M["阿希礼<br/>终身爱慕"]
    C --> N["媚兰<br/>阿希礼之妻"]
    C --> O["查尔斯<br/>媚兰之弟"]
```

描述：以南方种植园社会为根节点，向下展开三大家族。奥哈拉家族为核心，展示斯嘉丽与家族成员及三任丈夫的关系。虚线标注斯嘉丽对阿希礼的执念，点明情感主线的错位。

## 图二：时代变迁网络图（Network Diagram）

展示南北战争前后南方社会的结构变化与人物命运交织。

```mermaid
graph LR
    A["战前南方<br/>种植园文明"]
    B["南北战争爆发<br/>社会秩序崩塌"]
    C["战后重建<br/>旧秩序瓦解"]
    D["新南方崛起<br/>商业资本主义"]
    E["斯嘉丽<br/>从贵妇到商人"]
    F["阿希礼<br/>旧时代遗民"]
    G["瑞德<br/>乱世投机者"]
    A --> B
    B --> C
    C --> D
    E -.适应.-> D
    F -.无法适应.-> C
    G -.预见并获利.-> D
    B -.摧毁.-> A
```

描述：以时间为横向轴线，展示南方社会从战前到战后的四个阶段。三个人物以不同方式应对时代变迁：斯嘉丽适应新世界，阿希礼无法适应，瑞德预见并获利。箭头标明各自与时代的关系。

## 图三：斯嘉丽成长路径图（Path Diagram）

展示斯嘉丽从天真少女到坚韧女性的成长轨迹。

```mermaid
graph TD
    A["天真任性的<br/>庄园大小姐"]
    B["战争爆发<br/>初次面对死亡"]
    C["战火中为媚兰接生<br/>独自驾车回家"]
    D["塔拉庄园废墟<br/>发誓不再挨饿"]
    E["三次婚姻<br/>为生存不择手段"]
    F["经营锯木厂<br/>成为成功商人"]
    G["失去一切<br/>回归塔拉土地"]
    A --> B
    B --> C
    C --> D
    D --> E
    E --> F
    F --> G
    G -.领悟.-> H["明天又是新的一天<br/>精神的重生"]
```

描述：以单向路径展示斯嘉丽的成长轨迹，每个节点代表她人生中的关键转折点。从依赖他人的少女到独立生存的女性，最终在失去一切后回归土地，完成精神层面的重生。

## 图四：核心主题关系图（Graph Diagram）

```mermaid

    A["生存"]
    B["爱情"]
    C["土地"]
    D["旧南方文明"]
    E["女性独立"]
    F["执念与觉醒"]
    G["希望"]
    A --> E
    C --> A
    D -.消逝.-> B
    B -.错位.-> F
    F --> G
    C --> G
    E --> G
    D -.被摧毁.-> A
```

描述：以"生存"和"希望"为核心节点，展示各主题之间的关系。土地是生存的基础，旧南方文明的消逝引发爱情错位，执念的觉醒通向希望。女性独立是生存的延伸。整体揭示书中最深层的主题逻辑。
