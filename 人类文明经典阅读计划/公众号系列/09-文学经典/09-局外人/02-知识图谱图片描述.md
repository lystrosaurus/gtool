# 《局外人》知识图谱图片描述

## 图一：主题树状图（Tree Diagram）

展示《局外人》核心主题的分层结构。

```mermaid
graph TD
    A["《局外人》核心主题"] --> B["荒谬哲学"]
    A --> C["社会规训"]
    A --> D["存在主义"]
    B --> B1["世界无意义"]
    B --> B2["人类渴求意义"]
    B --> B3["两者冲突=荒谬"]
    C --> C1["情感标准化"]
    C --> C2["行为模板化"]
    C --> C3["异端者被放逐"]
    D --> D1["自由选择在己"]
    D --> D2["真实即反抗"]
    D --> D3["无意义中创造意义"]
```

**设计说明：** 从上至下，三层结构。顶层为书名，中间层为三大主题（荒谬哲学、社会规训、存在主义），底层为各主题的具体展开。整体呈现树状，背景用冷色调，体现小说的冷静基调。

## 图二：人物关系网络图（Network Diagram）

展示小说中人物之间的关系及其象征意义。

```mermaid
graph LR
    A["默尔索\n主人公/局外人"] ---|"冷漠/无感情"| B["玛丽\n女友/肉体关系"]
    A ---|"邻居/利用"| C["雷蒙\n皮条客/社会边缘人"]
    A ---|"对立/审判"| D["检察官\n社会道德代言人"]
    A ---|"无关/被杀"| E["阿拉伯人\n无名受害者"]
    A ---|"亲情/疏离"| F["母亲\n养老院的死者"]
    C ---|"冲突/引路人"| E
    D ---|"道德指控"| F
    B ---|"爱情/被拒绝"| A
```

**设计说明：** 以默尔索为中心节点，五条边连接五个关键人物。每条边标注关系性质。检察官与母亲之间有间接联系（检察官用母亲之死攻击默尔索）。雷蒙与阿拉伯人有直接冲突。背景用网格状暗纹，体现社会网络对人物的围困。

## 图三：叙事时间路径图（Path Diagram）

展示小说两部分的叙事走向，以及默尔索心理状态的转变。

```mermaid
graph LR
    A["母亲去世\n麻木接受"] --> B["守灵夜\n无泪无悲"]
    B --> C["葬礼次日\n约会看电影"]
    C --> D["海滩枪杀\n阳光刺眼"]
    D --> E["被捕入狱\n等待审判"]
    E --> F["法庭审判\n被审判灵魂"]
    F --> G["被判死刑\n拒绝神父"]
    G --> H["临死觉醒\n感到幸福"]
    
    style A fill:#e8e8e8
    style B fill:#e8e8e8
    style C fill:#e8e8e8
    style D fill:#ffcccc
    style E fill:#ffcccc
    style F fill:#ffcccc
    style G fill:#ccffcc
    style H fill:#ccffcc
```

**设计说明：** 从左至右的单线叙事路径。前半部分（灰色）表现默尔索的麻木与无感，中间部分（红色）代表暴力与审判的转折，结尾部分（绿色）象征觉醒与释然。颜色渐变体现心理状态的三层变化。

## 图四：荒谬哲学概念关系图（Concept Graph）

展示加缪荒谬哲学的核心概念及其内在关联。

```mermaid
graph TD
    A["荒谬"] -->|"产生于"| B["世界的沉默"]
    A -->|"产生于"| C["人类对意义的渴望"]
    B -.->|"冲突"| C
    A -->|"三种回应"| D["自杀\n逃避荒谬"]
    A -->|"三种回应"| E["信仰\n跳跃式逃避"]
    A -->|"三种回应"| F["反抗\n直面荒谬"]
    F --> G["保持清醒"]
    F --> H["拒绝幻想"]
    F --> I["活在当下"]
    G -.->|"默尔索的选择"| I
    H -.->|"默尔索的选择"| I
    
    style A fill:#ffcc00
    style F fill:#00ccff
    style D fill:#ff6666
    style E fill:#ff6666
```

**设计说明：** 以"荒谬"为核心节点，向上追溯其来源（世界的沉默 vs 人类对意义的渴望），向下展开三种回应方式。自杀与信仰用红色标注（加缪认为都是逃避），反抗用蓝色标注（加缪推崇的态度）。默尔索最终选择了反抗之路。背景用抽象几何图形，体现哲学思辨感。
