## ◇ 图一：人性论核心概念分类树

本图以树状结构展示《人性论》三大卷的核心概念层级关系。

```mermaid
graph TD
    ROOT["《人性论》<br/>大卫·休谟 1739-1740"]
    
    ROOT --> V1["卷一：论知性<br/>Understanding"]
    ROOT --> V2["卷二：论情感<br/>Passions"]
    ROOT --> V3["卷三：论道德<br/>Morals"]
    
    V1 --> V1A["印象与观念<br/>Impressions & Ideas"]
    V1 --> V1B["观念的联想<br/>Association of Ideas"]
    V1 --> V1C["因果关系<br/>Causation"]
    V1 --> V1D["归纳问题<br/>Problem of Induction"]
    V1 --> V1E["实体与自我<br/>Substance & Self"]
    
    V2 --> V2A["直接情感<br/>Direct Passions"]
    V2 --> V2B["间接情感<br/>Indirect Passions"]
    V2 --> V2C["意志与自由<br/>Will & Liberty"]
    
    V3 --> V3A["道德区分<br/>Moral Distinctions"]
    V3 --> V3B["正义的起源<br/>Origin of Justice"]

```

**图注：** 休谟将人性研究分为知性、情感、道德三个维度，构建了从认识论到伦理学的完整体系。分类树从三大卷出发，逐层展开核心概念，展现了《人性论》的知识架构。

graph LR

## ◇ 图三：因果推理的心理路径图

本图以流程图形式展示休谟对因果推理的解构过程，揭示"因果必然性"如何从心理习惯中产生。

```mermaid
flowchart TD
    A["观察事件A发生"] --> B["观察事件B随后发生"]
    B --> C{"A与B恒常结合?<br/>Constant Conjunction"}
    C -->|多次重复| D["心灵产生习惯性联想<br/>Customary Association"]
    D --> E["产生'必然联系'的感觉<br/>Feeling of Necessary Connection"]
    E --> F["断言'A导致B'<br/>Causal Claim"]
    
    G["客观世界"] -.->|只有恒常结合| B
    H["因果必然性<br/>不存在于客观世界"] -.->|仅存在于| D
    
    style F fill:#e8a0a0,stroke:#c0392b,stroke-width:2px
    style H fill:#d0e8a0,stroke:#27ae60,stroke-width:2px
```

**图注：** 休谟指出，因果推理的关键环节不在客观世界，而在心灵的习惯性联想。我们感受到的"必然性"是一种心理状态，而非事物本身的属性。红色标记揭示因果断言的脆弱性，绿色标记指出休谟的核心洞见。

## ◇ 图四：印象-观念-信念网络图

本图以网络结构展示休谟认识论中核心概念之间的关系，包括印象、观念、记忆、想象和信念的相互作用。

```mermaid
graph TB
    IMPRESSION["感觉印象<br/>Impression<br/>原初/强烈/生动"]
    
    IMPRESSION --> MEMORY["记忆观念<br/>Memory<br/>保留印象的生动性"]
    IMPRESSION --> IMAGINATION["想象观念<br/>Imagination<br/>自由组合/较弱"]
    
    MEMORY --> BELIEF["信念<br/>Belief<br/>生动的观念"]
    IMAGINATION -.->|缺乏信念力量| FICTION["虚构<br/>Fiction"]
    
    HABIT["心理习惯<br/>Custom/Habit"] --> BELIEF
    HABIT --> ASSOCIATION["观念联想<br/>Association"]
    
    ASSOCIATION --> SIMILARITY["相似关系<br/>Resemblance"]
    ASSOCIATION --> CONTIGUITY["时空接近<br/>Contiguity"]
    ASSOCIATION --> CAUSATION["因果关系<br/>Cause & Effect"]
    
    CAUSATION --> BELIEF
    
    REASON["理性<br/>Reason"] -.->|情感驱动| BELIEF
    
    style IMPRESSION fill:#a0d0f0,stroke:#2980b9,stroke-width:2px
    style BELIEF fill:#f0d0a0,stroke:#e67e22,stroke-width:2px
    style HABIT fill:#d0f0a0,stroke:#27ae60,stroke-width:2px
```

**图注：** 休谟的认识论网络中，感觉印象是知识的起点，信念是"生动的观念"，而心理习惯是连接印象与信念的桥梁。蓝色标记起点，橙色标记核心产物，绿色标记关键机制。理性在此网络中处于从属位置。
