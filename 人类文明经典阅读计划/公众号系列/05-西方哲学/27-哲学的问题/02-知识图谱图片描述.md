# 知识图谱图片描述：《哲学的问题》

## 图片一：哲学核心问题分类树

### 使用场景
用于文章开头，帮助读者快速了解《哲学的问题》涵盖的核心问题及其层次结构。

### Mermaid 图表代码

```mermaid
graph TD
    ROOT["《哲学的问题》核心问题"]

    ROOT --> K["知识论"]
    ROOT --> M["形而上学"]
    ROOT --> V["哲学的价值"]

    K --> K1["亲知的知识"]
    K --> K2["描述的知识"]
    K --> K3["归纳法问题"]

    M --> M1["外部世界是否存在"]
    M --> M2["物质与意识的关系"]
    M --> M3["真理的性质"]

    V --> V1["批判思维训练"]
    V --> V2["问题意识觉醒"]
    V --> V3["认知视野拓展"]

    classDef root fill:#2c3e50,color:#fff,stroke:#34495e
    classDef level1 fill:#3498db,color:#fff,stroke:#2980b9
    classDef level2 fill:#ecf0f1,color:#2c3e50,stroke:#bdc3c7

    class ROOT root
    class K,M,V level1
    class K1,K2,K3,M1,M2,M3,V1,V2,V3 level2
```

### 视觉说明
- 根节点为深色背景，表示总领全书
- 三大分支用蓝色区分，对应知识论、形而上学、价值论
- 叶子节点用浅色，表示具体问题
- 整体呈自上而下的树状结构，逻辑清晰

### 排版建议
- 图片宽度适配移动端，建议 690px
- 下方可加简短说明文字："罗素将哲学问题分为三大领域，上图展示了本书的核心问题框架"

## 图片二：重要人物思想关系图谱

### 使用场景
用于介绍罗素思想渊源的段落，展示哲学家之间的继承与批判关系。

### Mermaid 图表代码

```mermaid
graph LR
    DESC["笛卡尔\n我思故我在"] --> RUS["罗素\n逻辑分析"]
    HUME["休谟\n经验主义/怀疑论"] --> RUS
    LOCKE["洛克\n经验论"] --> HUME
    PLATO["柏拉图\n理念论"] --> DESC
    KANT["康德\n先验哲学"] --> RUS

    RUS --> EMP["经验材料"]
    RUS --> LOG["逻辑构造"]
    RUS --> IND["归纳问题"]

    classDef philosopher fill:#e74c3c,color:#fff,stroke:#c0392b
    classDef concept fill:#f39c12,color:#fff,stroke:#d68910

    class DESC,HUME,LOCKE,PLATO,KANT,RUS philosopher
    class EMP,LOG,IND concept
```

### 视觉说明
- 左侧为历史上的哲学家，用红色系标识
- 右侧为罗素的核心概念，用橙色系标识
- 箭头表示思想的继承和发展关系
- 罗素处于中心位置，汇聚多位哲学家的思想

### 排版建议
- 此图为横向布局，移动端可能需要左右滑动
- 可考虑将图片分段展示，或改为竖向排列

## 图片三：从感知到知识的推理路径

### 使用场景
用于解释"亲知的知识"与"描述的知识"之间关系的段落。

### Mermaid 图表代码

```mermaid
flowchart LR
    A["感官体验\n颜色/形状/声音"] --> B["感觉材料\nSense-data"]
    B --> C["物理对象假设\n桌子的独立存在"]
    C --> D["科学知识\n物理/化学性质"]

    A -.直接确定.-> E["亲知的知识"]
    C -.需要推理.-> F["描述的知识"]
    D -.依赖理论.-> G["可错的知识"]

    style A fill:#d5f5e3,stroke:#27ae60
    style B fill:#d5f5e3,stroke:#27ae60
    style C fill:#fadbd8,stroke:#e74c3c
    style D fill:#fadbd8,stroke:#e74c3c
    style E fill:#d4e6f1,stroke:#2980b9
    style F fill:#d4e6f1,stroke:#2980b9
    style G fill:#d4e6f1,stroke:#2980b9
```

### 视觉说明
- 左侧绿色系表示直接经验，确定性高
- 中间红色系表示推论假设，确定性降低
- 右侧蓝色系表示知识分类
- 实线箭头表示推理过程，虚线表示知识类型归属

### 排版建议
- 此图适合配合"确定性阶梯"的正文内容
- 可在图片下方添加说明："从感官体验到科学知识，确定性逐级递减"

## 图片四：哲学思维网络图

## 通用排版规范

### 图片样式
- 背景色：纯白或极浅灰 #fafafa
- 字体：系统默认无衬线字体
- 字号：节点文字 12-14px，标题 16-18px
- 线条：圆角矩形节点，曲线连接

### 移动端适配
- 图片最大宽度：690px
- 复杂图表建议拆分或使用横向滑动
- 每个图表下方保留 20px 间距

### 配色方案
- 主色：#2c3e50（深蓝灰）
- 辅色：#3498db（蓝）、#e74c3c（红）、#f39c12（橙）
- 背景：#ecf0f1（浅灰）、#fafafa（白）
- 强调：#8e44ad（紫）
