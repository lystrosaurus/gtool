# 存在主义行动挑战：7 天唤醒你的自由意识

> "生活从你敢于面对它的那一刻开始。" —— 萨特

---

## ◇ 序言：从理解到行动

读了萨特的哲学，理解了存在先于本质、人是自由的、绝对责任这些概念，然后呢？

然后，**你需要行动。**

存在主义从来不是一种纯粹的学术兴趣。萨特自己就是一个"介入型"知识分子——他写小说、办杂志、参加社会运动、拒绝诺贝尔奖。对他来说，**哲学必须通过行动来验证。**

这个 7 天行动计划，不是要你变成一个存在主义哲学家，而是要你把萨特的核心洞见，转化为日常生活中可以实践的具体行动。

每一天，一个挑战。不复杂，但需要你认真对待。

---

## ◆ 第一天：发现你的"自欺"时刻

### 挑战主题：识别自欺

萨特认为，人最常见的状态是自欺（Bad Faith）——明明知道自己是自由的，却假装自己不自由。

### 今天的任务

**准备一个笔记本或手机备忘录。**

在今天结束之前，记录下你捕捉到的 3 个"自欺"时刻。

### 常见的自欺信号

- "我没办法……"（你真的没办法吗？）
- "我就是这种人……"（你真的是"天生"如此吗？）
- "社会就是这样……"（你真的没有任何反抗的空间吗？）
- "等时机成熟……"（谁来决定什么是"时机成熟"？）
- "我没得选择……"（不选择，也是一种选择）

### 记录格式

```
场景：
我的想法/说法：
这为什么可能是自欺：
我其实可以选择的是：
```

### 示例

```
场景：下午开会时领导提出一个我认为不合理的方案
我的想法：反正我也改变不了什么，说了也没用
这为什么可能是自欺：我预设了自己的意见没有价值，
    预设了领导不会接受不同声音
我其实可以选择的是：用合适的方式表达不同意见
```

## ◇ 第二天：做一个"存在先于本质"的决定

### 挑战主题：打破自我设限

你一直以来认为自己是"某种人"——内向的、不善表达的、不适合领导的、不擅长社交的。

今天，选择一件事，做一次与"你就是这样的人"相反的行动。

### 今天的任务

**选择一件你一直想做但觉得"我不适合做"的事。**

然后去做。

### 行动方向参考

- 你觉得自己不善表达？今天在群里主动发一条有观点的发言
- 你觉得自己不适合社交？今天主动和一个不太熟的同事/朋友打招呼聊天
- 你觉得自己不会领导？今天主动承担一次小组讨论的组织工作
- 你觉得自己不够优秀？今天投递一份你一直觉得"够不上"的机会
- 你觉得自己做不到？今天开始一个你觉得"太难"的学习计划

### 关键心态

你不需要"成功"。你需要的是**体验选择的自由**。

即使结果不尽如人意，你也已经做了一件重要的事：**你用行动证明了，你不是被定义的。**

---

## ◆ 第三天：承担一次绝对责任

### 挑战主题：停止甩锅

萨特说，你必须为你的选择负全部责任。不是大部分责任，不是部分责任，而是**绝对责任**。

今天，练习在任何情况下都不甩锅。

### 今天的任务

**无论今天发生什么不好的事，不要把责任推给任何外部因素。**

### 具体做法

当不好的事情发生时，用下面的句式来重新表述：

```
不是："因为 XXX，所以我才……"
而是："我选择了 XXX，导致了这个结果。"
```

### 示例

```
不是："因为客户太难沟通，所以项目延期了"
而是："我选择了用这种方式与客户沟通，导致了项目延期"

不是："因为时间太紧，所以质量不好"
而是："我选择了在这个时间安排下交付，质量没有达到预期"

不是："因为团队不配合，所以我没做好"
而是："我选择了用这种方式与团队协作，没有达到预期效果"
```

### 这不是自我攻击

承担绝对责任不是要你自责，而是要你**把注意力从"谁该负责"转移到"我能做什么"。**

当你停止甩锅，你就获得了改变的力量。

## ◇ 第四天：重新审视一段关系中的"凝视"

### 挑战主题：理解他者

"他人即地狱"不是说要远离他人，而是要理解人际关系的深层结构。

今天，选一段让你感到不适的关系，用萨特的"凝视"理论来分析它。

### 今天的任务

**选一段关系（职场、家庭、朋友），回答以下问题：**

### 分析框架

```
这段关系是：

1. 在这段关系中，我感受到的"凝视"是什么？
   （对方是如何看我的？把我固定为什么形象？）

2. 我是如何回应这种凝视的？
   （我接受了？我反抗了？我回避了？）

3. 我是否也在"凝视"对方？
   （我是如何看待对方的？把对方固定为什么形象？）

4. 如果双方都尝试承认对方的主体性，
   这段关系可能会有什么不同？
```

### 可能的发现

你可能会发现：

- 你一直以为对方在否定你，实际上对方也在焦虑自己的位置
- 你一直在反抗对方的凝视，但反抗本身也是一种被凝视定义的回应
- 真正的自由不是摆脱他者，而是在与他者的关系中找到本真的存在方式

## ◆ 第五天：创造你的工作意义

### 挑战主题：意义的主动赋予

世界没有先天的意义。工作的意义也不是天生就有的。**意义是你自己创造出来的。**

今天，为你的工作赋予一个你选择的、你认同的意义。

### 今天的任务

**回答三个问题，然后基于回答，写下一段你的"工作意义宣言"。**

### 三个问题

```
问题一：在这份工作中，什么时刻让我感到有意义？
    （不是因为外部奖励，而是内心的满足感）

问题二：如果这份工作明天就没有了，
    我最舍不得的是什么？

问题三：如果我可以完全自由地选择，
    我希望通过工作实现什么？
```

### 工作意义宣言模板

```
我的工作意义是：
[用一段话描述你为工作赋予的意义]

我选择这个意义，因为：
[解释为什么这个意义对你重要]

我将通过以下行动来践行这个意义：
[列出 2-3 个具体的行动]
```

### 示例

```
我的工作意义是：通过我的专业能力，帮助他人解决问题，
    让世界因为我而有一点点不同。

我选择这个意义，因为我相信每个人的工作都可以产生
    真实的影响，无论这个影响看起来有多小。

我将通过以下行动来践行这个意义：
1. 每天花 15 分钟思考如何让我的工作成果更好
2. 主动帮助一位同事解决专业问题
3. 每周记录一件因为我的工作而产生的积极变化
```

## ◇ 第六天：面对自由的眩晕

### 挑战主题：与焦虑共处

克尔凯郭尔说焦虑是"自由的眩晕"。当你意识到你有选择的自由时，焦虑就来了。

今天，不逃避焦虑，而是与它共处。

### 今天的任务

**找出一个让你焦虑的选择，然后完整地体验这种焦虑。**

### 具体步骤

**第一步：识别焦虑**

找一个安静的时间，闭上眼睛，感受让你焦虑的那个选择。不要压抑它，不要转移注意力，就感受它。

**第二步：分析焦虑**

拿出纸笔，回答以下问题：

```
我焦虑的是：

这种焦虑在告诉我什么？
（它是在保护我？还是在限制我？）

如果我做出了这个选择，最坏的结果是什么？
我能承受吗？

如果我回避这个选择，五年后的我会怎么想？
```

**第三步：做出选择**

焦虑不会消失。但你可以**带着焦虑做出选择**。

这就是萨特的意思：**自由不是没有恐惧，而是在恐惧中依然选择。**

## ◆ 第七天：写下你的"存在宣言"

### 挑战主题：本真存在的承诺

经过前六天的练习，你已经体验了发现自欺、打破设限、承担责任、理解他者、创造意义、面对焦虑。

今天，把这一切整合成一份属于你的"存在宣言"。

### 今天的任务

**写下一份 300-500 字的存在宣言，作为你对自己的承诺。**

### 宣言参考框架

```
关于存在：
我相信存在先于本质。我不是被定义的，我是在自我定义的。
我相信……

关于自由：
我被判定为自由。我无法逃避选择。
我选择……

关于责任：
我为我的一切选择承担绝对责任。
我承诺……

关于他者：
我在关系中理解自我。我不回避冲突，也不回避理解。
我愿意……

关于行动：
哲学不只是理解，更是行动。
从今天起，我将……
```

### 把宣言放在哪里？

- 存在手机备忘录的置顶位置
- 打印出来贴在办公桌前
- 分享给一个信任的朋友，让 TA 监督你
- 每周回顾一次，持续一个月

## ○ 写在最后：自由是一种实践

萨特的存在主义不是用来"知道"的，而是用来"活出来"的。

这 7 天的挑战，不是要你完成什么伟大的目标，而是要你体验一件简单却深刻的事：

> **你是自由的。你一直都是。你只是需要敢于承认它，并付诸行动。**

当你完成了这 7 天的挑战，你会发现自己并没有变成另一个人。你还是你。

但有些东西已经不同了——**你看自己的方式不同了。**

你不再是被动的承受者，而是主动的选择者。你不再是环境的产物，而是意义的创造者。

这就是存在主义给你的礼物。
