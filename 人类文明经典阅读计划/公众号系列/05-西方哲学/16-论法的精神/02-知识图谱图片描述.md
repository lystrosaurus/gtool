## 图表一：政体分类树

**用途**：展示孟德斯鸠的三种政体及其核心原则

```mermaid
graph TD
    A[孟德斯鸠政体分类] --> B[共和政体]
    A --> C[君主政体]
    A --> D[专制政体]

    B --> B1[民主共和]
    B --> B2[贵族共和]
    B1 --> B1a[原则: 美德]
    B2 --> B2a[原则: 节制]

    C --> C1[原则: 荣誉]
    C --> C2[中间力量: 贵族/教会/城市]
    C --> C3[法律至上]

    D --> D1[原则: 恐惧]
    D --> D2[无中间力量]
    D --> D3[一人独裁]

    style A fill:#2c3e50,color:#fff
    style B fill:#27ae60,color:#fff
    style C fill:#2980b9,color:#fff
    style D fill:#c0392b,color:#fff
```

**图片说明**：
此图为垂直层级分类树，顶部为总分类节点，向下分为三大政体分支。共和政体进一步细分为民主共和与贵族共和。每个政体节点下方标注其核心维系原则。配色方案以深色总节点、绿色共和、蓝色君主、红色专制区分。

    C -.->|违宪审查| B

    subgraph 权力来源
        P[人民]
    end

    P --> A
    P --> B
    P --> C

    style A fill:#3498db,color:#fff
    style B fill:#e67e22,color:#fff

**图片说明**：
此图为横向循环关系图，展示三权之间的相互作用。实线箭头表示权力分工：立法制定法律、行政执行法律、司法裁决争端。虚线箭头表示制衡机制：相互监督、弹劾、否决和违宪审查。底部"人民"节点表示三权最终来源于人民授权。

## 图表五：自由与专制对比图

**用途**：对比不同制度下公民自由的状态

```mermaid
graph LR
    subgraph 自由社会
        F1[法治保障] --> F2[权力分立]
        F2 --> F3[个人权利]
        F3 --> F4[可预期的生活]
        F4 --> F5[免于恐惧]
    end

    subgraph 专制社会
        T1[人治统治] --> T2[权力集中]
        T2 --> T3[权利无保障]
        T3 --> T4[不可预期的生活]
        T4 --> T5[恐惧与服从]
    end

    F5 -.对比.-> T5

    style F1 fill:#27ae60,color:#fff
    style T1 fill:#c0392b,color:#fff
```

**图片说明**：
此图为左右对比结构图。左侧为自由社会的正向循环：法治保障导致权力分立，权力分立保护个人权利，个人权利带来可预期的生活，最终实现"免于恐惧"的自由。右侧为专制社会的负向循环：人治导致权力集中，权力集中使权利无保障，最终陷入"恐惧与服从"。中间虚线标注两者的核心差异。
