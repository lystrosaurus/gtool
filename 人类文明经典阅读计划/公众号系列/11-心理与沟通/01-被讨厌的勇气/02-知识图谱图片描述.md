# 知识图谱图片描述 - 被讨厌的勇气

本文档包含 4 张 Mermaid 知识图谱的描述与代码，用于可视化《被讨厌的勇气》核心概念体系。

## 图一：阿德勒心理学核心概念树

以阿德勒心理学为根节点，逐层展开书中核心概念的树状结构图。

```mermaid
graph TD
    A["阿德勒心理学"] --> B["目的论"]
    A --> C["课题分离"]
    A --> D["共同体感觉"]
    A --> E["横向关系"]

    B --> B1["不是过去决定现在"]
    B --> B2["当下的目的决定行为"]
    B --> B3["人可以随时改变"]

    C --> C1["分清谁的课题"]
    C --> C2["不干涉他人课题"]
    C --> C3["不让他人干涉自己"]

    D --> D1["他者贡献"]
    D --> D2["他者信赖"]
    D --> D3["他者接受"]

    E --> E1["不批评不表扬"]
    E --> E2["鼓励代替评价"]
    E --> E3["平等而非竞争"]
```

## 图三：课题分离实践路径

以路径图的形式，展示从困扰到自由的实践步骤。

```mermaid
graph TD
    A["遇到人际困扰"] --> B["判断：这是谁的课题？"]
    B --> C{"后果由谁承担？"}
    C -->|自己承担| D["这是你的课题"]

    E --> G["尊重他人的选择"]

    H --> I["获得自由"]
```
