# 知识图谱图片描述 - 终身成长

本文档包含 4 张 Mermaid 知识图谱的描述与代码，用于可视化《终身成长》核心概念体系。

---

## 图一：两种思维模式对比树

以两种思维模式为根节点，逐层对比其信念、行为和结果的树状结构图。

```mermaid
graph TD
    A["思维模式"] --> B["固定型思维"]
    A --> C["成长型思维"]

    B --> B1["信念：能力固定"]
    B --> B2["行为：回避挑战"]
    B --> B3["面对失败：证明自己不行"]
    B --> B4["看待努力：无能的标志"]
    B --> B5["看待他人成功：威胁"]

    C --> C1["信念：能力可发展"]
    C --> C2["行为：迎接挑战"]
    C --> C3["面对失败：学习机会"]
    C --> C4["看待努力：成长路径"]
    C --> C5["看待他人成功：灵感"]
```

## 图二：思维模式影响网络

展示思维模式如何影响行为、情绪和结果的关联网络。

```mermaid
graph LR
    A["固定型思维"] --- B["害怕挑战"]

    B --- E["待在舒适区"]
    C --- E
    D --- E

    E --- F["能力停滞"]

    J --- L
    K --- L

    L --- M["能力不断提升"]

```

## 图三：从固定型到成长型的转变路径

以路径图的形式展示思维模式转变的步骤。

```mermaid
graph TD
    A["识别固定型思维"] --> B["觉察触发场景"]
    B --> C["挑战时害怕"]
    B --> D["失败后自我否定"]
    B --> E["看到他人成功感到威胁"]

    C --> F["固定型思维人格的声音"]
    D --> F
    E --> F

    F --> G["用成长型思维回应"]
    G --> G1["挑战是成长机会"]
    G --> G2["失败是反馈"]
    G --> G3["他人成功是灵感"]

    G1 --> H["采取成长型行动"]
    G2 --> H
    G3 --> H

    H --> I["持续练习"]
    I --> J["成长型思维内化"]
```
