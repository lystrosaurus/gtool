# 知识图谱图片描述 - 《蛤蟆先生去看心理医生》

## 图一：三种自我状态树状图

**类型：** tree graph
**用途：** 展示沟通分析理论中的三种自我状态及其典型行为

```mermaid
graph TD
    A["自我状态"] --> B["儿童自我状态"]
    A --> C["父母自我状态"]
    A --> D["成人自我状态"]
    B --> B1["依赖型儿童"]
    B --> B2["自由型儿童"]
    B --> B3["适应型儿童"]
    C --> C1["批判型父母"]
    C --> C2["照顾型父母"]
    C --> C3["教导型父母"]
    D --> D1["理性思考"]
    D --> D2["情感觉察"]
    D --> D3["自主行动"]
```

**视觉说明：** 顶部根节点"自我状态"，向下分三种状态，每种再分三个子类型。倒树形结构。配色建议：根节点深蓝，儿童状态用橙色，父母状态用红色，成人状态用绿色，子节点用对应浅色调。

## 图二：蛤蟆先生成长路径图

**类型：** path/flow diagram
**用途：** 呈现蛤蟆先生从依赖到独立的心理成长过程

```mermaid
flowchart LR
    A["抑郁状态"] --> B["第一次面谈"]
    B --> C["觉察儿童状态"]
    C --> D["识别父母状态"]
    D --> E["表达愤怒"]
    E --> F["进入成人状态"]
    F --> G["自我负责"]
    G --> H["心理独立"]
    H -.->|"持续成长"| G
```

**视觉说明：** 从左到右的线性成长路径。前半段（抑郁到觉察）用灰色调，中间（识别到愤怒）用橙色调，后半段（成人到独立）用绿色调。虚线箭头表示持续成长的过程。

## 图三：心理咨询过程网络图

**类型：** network/relationship graph
**用途：** 展示心理咨询中的关键要素及其关系

```mermaid
graph LR
    A["来访者"] --- B["咨询师"]
    A --- C["自我觉察"]
    B --- D["专业引导"]
    C --- E["行为模式识别"]
    D --- E
    E --- F["情绪表达"]
    C --- F
    F --- G["自我接纳"]
    E --- G
    G --- H["心理成长"]
    D -.->|"安全空间"| C
    B -.->|"共情理解"| G
```

**视觉说明：** 左侧为来访者和咨询师，中间为核心过程要素，右侧为成长结果。实线表示直接关系，虚线表示支持性关系。节点按流程阶段着色。

---

## 图四：心理疗愈循环图

**类型：** cycle diagram
**用途：** 呈现心理疗愈的循环迭代过程

```mermaid
flowchart TD
    A["觉察自我状态"] --> B["识别行为模式"]
    B --> C["表达真实情绪"]
    C --> D["接纳不完美的自己"]
    D --> E["做出新的选择"]
    E --> F["体验新的结果"]
    F -->|"深化觉察"| A
    C -.->|"可能需要多次"| B
    D -.->|"反复练习"| E
```

**视觉说明：** 顺时针循环结构。六个核心步骤均匀分布成圆形。实线箭头表示主循环，虚线箭头表示反馈强化。配色建议：渐变色环（蓝→绿→青→蓝），表示持续迭代。
