# 知识图谱图片描述 | 《心力》核心概念关系图

本文档描述《心力》知识图谱中需要生成的4张核心图片，分别使用不同的图表类型展示书中核心概念的逻辑关系。

## 图片一：心力构成要素树状图（Tree Diagram）

### 图表类型
Mermaid tree diagram

### 图表描述
展示"心力"作为根节点，向下分解为三大核心支柱，每个支柱再细分为具体能力要素。

### Mermaid 代码

```mermaid
graph TD
    A[心力] --> B[心理韧性]
    A --> C[专注力]
    A --> D[自我效能感]
    
    B --> B1[挫折承受力]
    B --> B2[压力管理力]
    B --> B3[情绪调节力]
    
    C --> C1[注意力聚焦]
    C --> C2[抗干扰能力]
    C --> C3[心流触发]
    
    D --> D1[自信心建立]
    D --> D2[目标感驱动]
    D --> D3[正向反馈循环]
```

### 视觉说明
- 根节点"心力"使用醒目的中心位置
- 三大支柱用不同颜色区分
- 子节点使用渐变色，体现层次递进

---

## 图片二：冠军心态训练网络图（Network Diagram）

### 图表类型
Mermaid network/graph diagram

### 图表描述
展示邓亚萍冠军心态训练体系中各要素之间的交叉关联关系，体现训练方法的系统性和互通性。

### Mermaid 代码

```mermaid
graph LR
    A[日常训练] --> B[技术打磨]
    A --> C[心理建设]
    A --> D[体能储备]
    
    B --> E[比赛表现]
    C --> E
    D --> E
    
    C --> F[目标设定]
    C --> G[压力模拟]
    C --> H[自我对话]
    
    F --> I[正向循环]
    G --> I
    H --> I
    
    E --> I
    
    style C fill:#e1f5fe
    style E fill:#fff3e0
    style I fill:#e8f5e9
```

### 视觉说明
- 节点大小根据重要程度区分
- 连线粗细表示关联强度
- 关键路径用高亮色标注

---

## 图片三：面对挫折的心路历程路径图（Path Diagram）

### 图表类型
Mermaid path/flow diagram

### 图表描述
展示一个人在面对挫折时，从消极反应到积极应对的心路历程转变路径。

### Mermaid 代码

```mermaid
graph TD
    A[遭遇挫折] --> B[第一阶段：情绪冲击]
    B --> C{选择回应方式}
    
    C -->|消极路径| D[抱怨外部环境]
    D --> E[陷入自我怀疑]
    E --> F[放弃尝试]
    
    C -->|积极路径| G[接纳负面情绪]
    G --> H[分析可控因素]
    H --> I[制定行动计划]
    I --> J[执行并调整]
    J --> K[获得成长]
    
    style A fill:#ffebee
    style C fill:#fff9c4
    style K fill:#e8f5e9
    style F fill:#f5f5f5
```

### 视觉说明
- 路径分叉点用菱形突出
- 消极路径用灰色调
- 积极路径用暖色调，传递正向能量

---

## 图片四：心力成长飞轮效应图（Graph Diagram）

### 图表类型
Mermaid circular/graph diagram

### 图表描述
展示心力培养的飞轮效应：每一次心理突破都会增强下一次面对挑战的信心，形成正向循环。

### Mermaid 代码

```mermaid
graph TD
    A[设定挑战目标] --> B[投入行动]
    B --> C[遇到困难]
    C --> D[调用心理韧性]
    D --> E[克服困难]
    E --> F[获得成就感]
    F --> G[自我效能感提升]
    G --> H[心力增强]
    H --> A
    
    F -.->|积累| I[心理资本]
    G -.->|积累| I
    H -.->|积累| I
    
    style A fill:#e3f2fd
    style H fill:#f3e5f5
    style I fill:#fff3e0
```

### 视觉说明
- 主循环用圆形排列，体现飞轮效应
- "心理资本"作为蓄水池，展示长期积累
- 箭头方向清晰，体现因果关系
