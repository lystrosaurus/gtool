# 知识图谱图片描述 | 《心流》核心概念关系图

本文档描述《心流》知识图谱中需要生成的4张核心图片，分别使用不同的图表类型展示契克森米哈赖心流理论的逻辑关系。

## 图片一：心流触发条件树状图（Tree Diagram）

### 图表类型
Mermaid tree diagram

### 图表描述
展示心流产生的核心条件及其子维度，以"心流"为根节点，逐层分解触发要素。

### Mermaid 代码

```mermaid
graph TD
    A[心流 Flow] --> B[清晰的目标]
    A --> C[即时反馈]
    A --> D[挑战与技能平衡]
    A --> E[全神贯注]
    
    B --> B1[目标明确可描述]
    B --> B2[目标具有挑战性]
    B --> B3[目标可分解执行]
    
    C --> C1[行为结果即时可见]
    C --> C2[能够调整改进]
    C --> C3[形成正向循环]
    
    D --> D1[挑战不过高避免焦虑]
    D --> D2[挑战不过低避免无聊]
    D --> D3[技能与挑战动态匹配]
    
    E --> E1[注意力完全集中]
    E --> E2[排除外部干扰]
    E --> E3[行动与意识合一]
```

### 视觉说明
- 根节点"心流"居中放大显示
- 四大条件用不同色系区分
- 子节点按逻辑层级排列

---

## 图片二：心流体验构成网络图（Network Diagram）

### 图表类型
Mermaid network/graph diagram

### 图表描述
展示心流体验的八大特征要素之间的交叉关联，体现心流状态的系统性和整体性。

### Mermaid 代码

```mermaid
graph LR
    A[全神贯注] --> B[行动意识合一]
    A --> C[自我意识消失]
    
    B --> D[掌控感]
    C --> D
    
    D --> E[时间感扭曲]
    D --> F[内在奖励]
    
    E --> G[体验本身就是目的]
    F --> G
    
    A -.->|支撑| H[心流通道]
    D -.->|强化| H
    G -.->|巩固| H
    
    style H fill:#fff3e0
    style A fill:#e3f2fd
    style G fill:#e8f5e9
```

### 视觉说明
- 核心特征节点用大圆形
- 关联连线用不同粗细表示关联强度
- "心流通道"节点用暖色高亮

---

## 图片三：挑战与技能的动态关系路径图（Path Diagram）

### 图表类型
Mermaid path/flow diagram

### 图表描述
展示一个人在面对不同挑战与技能匹配关系时的心理状态变化路径。

### Mermaid 代码

```mermaid
graph TD
    A[开始一项活动] --> B[评估挑战水平]
    B --> C[评估自身技能]
    
    C --> D{挑战 vs 技能}
    
    D -->|高挑战 低技能| E[焦虑 Anxiety]
    D -->|低挑战 高技能| F[无聊 Boredom]
    D -->|低挑战 低技能| G[冷漠 Apathy]
    D -->|高挑战 高技能| H[心流 Flow]
    
    E --> I[提升技能]
    I --> H
    
    F --> J[增加挑战]
    J --> H
    
    G --> K[寻找意义]
    K --> H
    
    H --> L[技能提升]
    L --> M[需要更高挑战]
    M --> H
    
    style H fill:#e8f5e9
    style E fill:#ffebee
    style F fill:#fff3e0
    style G fill:#f5f5f5
```

### 视觉说明
- 心流区域用绿色高亮
- 焦虑用红色，无聊用橙色，冷漠用灰色
- 从非心流状态到心流的路径用箭头标注

---

## 图片四：心飞轮效应图（Graph Diagram）

### 图表类型
Mermaid circular/graph diagram

### 图表描述
展示心流体验的正向循环机制：进入心流后如何持续提升自我，形成螺旋上升的成长路径。

### Mermaid 代码

```mermaid
graph TD
    A[设定清晰目标] --> B[投入专注行动]
    B --> C[获得即时反馈]
    C --> D[调整行为策略]
    D --> E[进入心流状态]
    E --> F[获得内在满足]
    F --> G[技能水平提升]
    G --> H[自我复杂度增加]
    H --> I[设定更高目标]
    I --> A
    
    F -.->|积累| J[心理熵降低]
    E -.->|积累| J
    G -.->|积累| J
    
    style A fill:#e3f2fd
    style E fill:#e8f5e9
    style J fill:#fff3e0
```

### 视觉说明
- 主循环用环形排列体现飞轮效应
- "心理熵降低"作为副产品展示
- 箭头方向体现因果循环关系
- 关键节点用颜色编码区分阶段
