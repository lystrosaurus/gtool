## 阅读路径推荐

### 初学者路径（前6个月）

```
月1: 认知觉醒 → 小狗钱钱 → 活着
月2: 被讨厌的勇气 → 论语(选读) → 人类简史
月3: 刻意练习 → 非暴力沟通 → 百年孤独
月4: 穷爸爸富爸爸 → 道德经(选读) → 思考快与慢
月5: 原则 → 史记(选读) → 被讨厌的勇气(重读)
月6: 七个习惯 → 艺术的故事(选读) → 万历十五年
```

### 进阶者路径（6-24个月）

```
月7-12: 深入哲学与科学
  - 理想国 → 形而上学 → 纯粹理性批判(选读)
  - 时间简史 → 物种起源 → 万物简史
  - 穷查理宝典 → 聪明的投资者 → 反脆弱

月13-24: 深化人文与专业
  - 红楼梦(全) → 资治通鉴(选读) → 西方哲学史
  - 巴菲特致股东的信 → 投资最重要的事 → 周期
  - 存在与时间(选读) → 精神现象学(选读) → 美学散步
```

### 高阶者路径（2-5年）

```
第3年: 系统研读原典
  - 四书五经(全) → 诸子百家(全) → 二十四史(选读)
  - 柏拉图全集(选) → 亚里士多德全集(选) → 康德三大批判
  - 证券分析 → 金融炼金术 → 资本论(选读)

第4-5年: 跨学科融合
  - 建立个人知识体系
  - 输出读书笔记与文章
  - 形成独特的世界观与方法论
```

## 使用说明

1. **从总目录选择感兴趣的分类**，点击进入对应文件
2. **每本书都有**: 作者、豆瓣评分、核心总结、阅读建议
3. **按照阅读路径推荐**，循序渐进，避免贪多嚼不烂
4. **每读完一本书**，在对应文件的追踪表中标记进度
5. **定期回顾** 5年成长计划，调整阅读节奏
